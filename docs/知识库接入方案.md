# 官方与个人知识库接入方案

## 范围与访问边界

知识库页面分为「我的知识库」「官方知识库」。官方列表只返回名称、用途及对应英文，不返回正文、文档清单、内部存储路径或凭证。官方库对所有登录用户的会话开放相关片段检索，不提供用户侧导出或管理能力。检索结果会送入模型用于回答，因此这是原文管理权限限制，不是“模型永远无法复述任何知识”的保密承诺。

个人库支持创建多个库、设置用途、启停、删除、管理文档、上传文件或粘贴文本、重试索引、检索测试和独立 Embedding 配置。所有读写和检索在服务端验证账号归属，不能通过传入其他用户的库 ID 越权。原有个人知识资料迁移到默认个人库，保留旧记录。

## 原生能力与持久化

AgentScope Text/PDF/Word/Excel/PPT Parser → ApproxTokenChunker → OpenAI 兼容或 Ollama Embedding → QdrantStore → KnowledgeBase.search。SQLite 保存账号权限、知识库、文档、索引状态和加密后的私有模型配置；Qdrant 本地目录保存向量，每库/Embedding 配置有独立 collection。片段包含文档、页码/工作表等来源信息。

通过统一检索服务接入会话自动检索和 search_documents 工具，替代旧知识资料的关键词注入。停用、删除、重建期间的文档不会被检索。重启恢复未完成索引，失败可重试；不以关键词命中伪装向量检索。

## 模型配置

官方库使用平台环境变量配置 Embedding，用户无法读取平台凭证。个人库可以使用平台默认或自己的 OpenAI 兼容/Ollama 配置。密钥加密保存，仅返回“已设置”；修改模型或维度会使旧索引失效并重建。未配置时文档显示待配置，不调用聊天模型代替 Embedding。

## 首期内容与验收

内置「商品内容规范」中英文资料。验证官方目录字段白名单、禁止原文读取与管理、跨用户隔离、真实 SDK 切片/向量写入及持久化、索引失败重试、删除与禁用立即停止召回、会话工具接入，以及中英文页面。真实模型密钥和模型服务需配置后才能完成线上语义效果验收。

## 免费云端与启动配置

推荐组合为 Cloudflare Workers AI 的多语言 BGE-M3 + Qdrant Cloud 免费集群。Cloudflare 通过 OpenAI 兼容 Embedding 接口接入；Qdrant Cloud 继续使用 AgentScope 原生 QdrantStore。免费额度与闲置暂停策略以服务商当前说明为准，详情见 [Cloudflare 定价](https://developers.cloudflare.com/workers-ai/platform/pricing/) 和 [Qdrant 免费集群](https://qdrant.tech/documentation/cloud/create-cluster/)。没有自动开通云资源，也不会自动上传源文档到未知服务。

平台管理员在项目 `.env` 或服务环境中填写：

```dotenv
XIXI_KB_EMBEDDING_PROVIDER=openai
XIXI_KB_EMBEDDING_MODEL=@cf/baai/bge-m3
XIXI_KB_EMBEDDING_BASE_URL=https://api.cloudflare.com/client/v4/accounts/YOUR_ACCOUNT_ID/ai/v1
XIXI_KB_EMBEDDING_DIMENSIONS=1024
XIXI_KB_EMBEDDING_API_KEY=YOUR_WORKERS_AI_API_TOKEN
XIXI_KB_QDRANT_URL=https://YOUR_CLUSTER.cloud.qdrant.io:6333
XIXI_KB_QDRANT_API_KEY=YOUR_QDRANT_KEY
```

不配置 Qdrant URL 则使用 `service/state/knowledge_vectors` 本地持久化，无需 Docker 或独立数据库进程。不配置 Embedding 不会自动下载模型，文档显示待配置，真实语义检索需配置有效服务后才能使用。配置后重启 Python 服务；待配置文档会重新进入队列。向量源、原始资料、账号数据库及 `knowledge.key` 应一起备份。平台向量服务凭证不通过用户 API 返回。

个人可在知识库设置中选择自己的 OpenAI 兼容或 Ollama Embedding，平台默认则使用上述配置。改变模型、维度或服务地址将重建索引；向量维度必须匹配模型实际输出。迁移向量存储地址前应迁移向量数据，或在新存储中重建全部索引。
