# 技能市场与会话调用

入口：能力市场 → 技能 → 技能市场。

已安装 Anthropic 官方仓库的六个完整技能包：pdf、docx、xlsx、pptx、frontend-design、mcp-builder。文件保存在 `service/skills/`，保留原始 SKILL.md、参考文档、脚本和 LICENSE.txt。来源为 https://github.com/anthropics/skills ，市场提供每个技能的来源链接，账号资源记录 SKILL.md 的 SHA-256。

## 使用方式

首次进入技能列表或发起会话时，会为当前账号登记这六个已启用技能。已安装技能中可编辑主指令、停用和删除，状态按账号持久化，刷新与重启不会自动恢复已删除或已停用的技能。删除后可在市场重新安装。

会话入口：「新建任务」聊天框 → ＋ → 技能／MCP 连接器。每轮可分别指定最多 3 个技能和 3 个 MCP，使用 skill_ids／mcp_ids 随本轮请求提交，标签代表用户优先选择。提交后界面清空选择，下一轮不继承，审批恢复保留同一轮选择。智能体配置不限制绑定数量，每轮选择只能来自其配置范围；消息渠道不提供网页会话技能选择。

选择技能后，会话示例：

- 请调用 pdf 技能，先读取完整技能内容，再说明提取 PDF 表格的处理流程。
- 使用 frontend-design 技能，为我的电商后台设计首页。
- 使用 mcp-builder 技能，读取 Python 参考文档后给出服务实现方案。

模型每轮收到当前智能体可用技能的名称、说明与资源 ID，并单独标明本轮用户指定项。技能目录较大时通过 list_available_skills 分页读取，候选存在相似能力时先询问用户；用户指定与任务完全不匹配时先确认是否按自然语言任务继续。模型，再通过 `read_skill(skill_id, path, offset, limit)` 读取指令。`list_skill_files(skill_id)` 提供包内文件清单。主指令从 SKILL.md 开始，按引用继续读取参考文件；长文件通过 next_offset 分段读完，不会把六个技能全文都挤入初始上下文。

市场中的「查看技能内容」使用相同的文件读取能力，支持切换文件和继续读取。自定义技能也支持 read_skill，只有一个 SKILL.md 文件。

## 权限与执行范围

读取仅允许当前账号已启用的技能。自建智能体会话及定时任务必须满足智能体配置白名单；未声明绑定时不继承全部账号技能，显式选择不直接扩大白名单。用户明确要求使用的配置外平台市场技能，可经 configure_market_skill 校验来源、归属、启用及智能体配置权限后持久化绑定并对当前会话生效，成功后必须明确告知用户；停用、无权访问和非市场技能不自动配置。渠道配置不接收技能选择，渠道会话不能从网页覆盖能力范围。读取拒绝绝对路径、上级路径、目录越界、超大文件和非 UTF-8 二进制文件。客户端提交 package/source 等字段不能赋予磁盘文件访问权限。

本次完成技能安装、内容查看和会话按需加载。技能目录中的脚本不会自动执行，也未新增通用 Python、Shell 或文件生成运行环境；实际文档解析、生成和下载仍取决于会话已接入的执行工具与依赖。模型不得声称已执行当前工具无法完成的操作。

## 验证

服务测试覆盖完整安装、持久化、删除后重装、所有主指令逐段读取、引用文件读取、跨账号拒绝、会话范围、停用、路径越界、来源伪造、HTTP 鉴权及 AgentScope 实际工具调用。前端验证市场卡片、安装状态、内容预览及文件切换；不调用付费外部模型。
