# 会话下一步建议

所有工作空间智能体通过 `BootstrapMiddleware` 统一接收下一步建议协议，包括自定义智能体。无需为每个智能体分别修改人设，也不需要额外请求模型生成建议。

模型在需要可选引导时，在回答末尾独立输出：

```xml
<suggest_prompts>[{"prompt":"请整理安装步骤。"},{"prompt":"请审查脚本安全风险。"}]</suggest_prompts>
```

数组每项只有 `prompt`。后端验证、去重后最多保留 4 项，每项最多 500 字符；格式异常、未完成或中断的建议不作为可点击操作。代码块中的协议示例保持正文展示。

后端从回答正文分离建议，保存到现有消息 `parts_json`：

```json
{"type":"data","name":"suggest_prompts","data":[{"prompt":"请整理安装步骤。"}]}
```

最终 `message_parts` SSE 同时携带清理后的 `content` 和结构化 `parts`。会话刷新后仍从原消息读取，无需数据库迁移。前端在流式过程中隐藏协议及跨分片的未完整标记，回答完成后展示 HeroUI 按钮。

按钮直接显示完整 `prompt`，点击填入当前会话输入框并聚焦，不自动发送。仅最新回答在会话空闲且正常完成时可操作，历史建议保留展示。必需的技能选择、执行授权和权限确认不使用此组件，点击建议不构成执行授权。

语言跟随当前对话，由模型生成；组件的无障碍标题使用全局中英文词典。
