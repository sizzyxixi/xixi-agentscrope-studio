# 商品库到经营中心刊登接入契约

## 1. 职责

商品库维护来源 SPU、SKU 和素材。列表刊登操作将选中范围与一家目标店铺交给经营中心，通过对应平台智能体对话处理资料及刊登。商品库不维护认领关系、草稿箱、已刊登清单、预刊登状态机或直接提交平台的本地适配器。

既有 products、products_sku 字段不变。claim_status 只保留历史数据含义，不作为当前刊登入口的条件，不展示为刊登状态。历史来源与素材数据继续读取，浏览器旧任务不恢复、不自动执行。

## 2. 范围与店铺

SPU 行刊登带全部有效 SKU，SKU 行刊登只带当前项，批量刊登使用明确勾选的商品及 SKU。createProductPublicationContext() 在跳转前以当前目录校验范围，重复选择去重；选中的商品或任一 SKU 已失效时阻止跳转，不静默遗漏或扩大选择。

每次只选一家启用、已授权且未过期的店铺。平台筛选、店铺搜索及分页沿用服务端授权资源；筛选与翻页保留单选，确认按完整集合核验。旧认领记录不阻止再次进入刊登会话。固定店铺示例仅供前端展示，不能作为真实来源权限的兜底。

## 3. 经营中心上下文

ProductPublicationContext 包含一家店铺的 ID、名称、平台、站点、币种，以及多件商品的业务编号、可编辑事实和具体选中 SKU。用于显示的商品图片与发送的事实分离，不将图片 base64、前端临时 ID 或历史工作流记录混入文本。

确认店铺后由 AgentWorkbench 进入正常经营中心首页，StoreEntry 选择对应平台智能体，输入框填入“将这批商品刊登到「XXX」店铺。”，显示全部所选商品卡片及 SKU 数量与货号。用户可修改文本、逐件取消引用；跳转不自动发送、不创建刊登任务、不显示本地刊登成功。

## 4. 发送契约

用户点击发送后，prepareStoreTask() 校验目标平台与智能体匹配，再创建该智能体会话及绑定附件。消息包含目标店铺与站点、每件商品的业务编号和资料、全部已选 SKU 的货号、规格、价格、重量和六项尺寸，未选 SKU 不参与。事实块随用户消息持久化；会话渲染识别版本化资料块，将商品显示为卡片、文字显示为用户实际指令，刷新后仍保持该轮范围，普通或损坏消息不被改写。

会话创建或附件上传失败保留输入，不进入伪造的对话页。认证、账号归属、店铺授权、商品可访问性及实际平台提交均由业务服务校验；前端带入的标识或授权快照不能代替服务端权限。

## 5. 执行与结果

经营智能体按目标平台整理资料、类目、图片、价格、库存和物流并执行刊登。商品库不自动调用准备／发布适配器，不将来源价格视为成本或目标店铺最终售价，不把自然语言回复当作真实接口结果。执行中断、幂等、平台回执和实际在售状态由经营服务处理，并在会话反馈或查询。

完整业务规则见[商品库管理需求文档](../../../PRD/商品库管理需求文档.md)。
