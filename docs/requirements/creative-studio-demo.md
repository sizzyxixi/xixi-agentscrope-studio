# 跨境商品创作工作台：产品架构与前端 Demo

## 信息架构

- 创作：图片创作、视频创作；商品参考图、创作描述、画幅、数量或时长；创作记录与推荐模板。
- 探索：平台模板、平台技能；搜索、场景筛选、使用模板、收藏。平台技能面向商品创作场景，Agent 能力市场保留为管理入口。
- 资产：素材库、商品库、知识库、收藏。长期目标是按工作空间统一管理资产，供创作与 Agent 共同引用。
- Agent（二级菜单）：新建任务、工作台概览、能力市场（保留智能体、技能、工作流、连接器）、自动化。
- 会话列表：保留原会话搜索、分组、管理与恢复能力。

## 核心闭环

上传商品参考 → 选择模板或描述需求 → 调整创作参数 → 提交生成 → 查看结果 → 编辑与导出 → 归档资产 → 再次引用。

## 当前 Demo 边界

默认进入创作页。CreativeStudio 独立承载三个新页面，AgentWorkbench 保留现有账号、会话和管理能力。切换页面保持组件挂载，保留当前参考图、收藏、草稿与演示记录；刷新后清空，未写入服务器或浏览器持久存储。

参考图支持 20MB 以内 JPG、PNG、WebP，通过 object URL 本地预览。模板缩略图为 SVG 场景示意。生成按钮仅添加明确标注的演示记录，无模型调用、无积分扣除、无真实生成结果。商品库目前演示参考图使用，完整商品建档待实现。知识库连接已有功能。

## 下一阶段

1. 商品档案：商品名、SKU、多角度图片、卖点、品牌规范，形成创作输入快照。
2. 生成任务：创建接口、持久状态、供应商适配、队列、状态恢复、失败重试与成本结算。
3. 媒体资产：私有对象存储直传、素材归档、版本、收藏持久化、筛选和授权下载。
4. 编辑交付：文字与版式图层、渠道规格导出；视频分镜、字幕、转码与拼接。
5. 探索运营：模板结构化参数和版本、技能执行入口、模板使用效果统计。

## 前后端边界

前端：创作参数、上传交互、模板选择、任务状态与产物展示。
业务 API：权限、商品与资产、任务状态、计费与幂等。
Worker：调用模型、查询状态、结果转存、FFmpeg 后处理。
Agent：通过同一业务 API 发起创作任务，提供卖点提炼、提示词和分镜建议。

## 创作首页 v2：参考 MasterGo 旧稿

参考文件 Moonclaw web-01，节点 185:688064。采用旧稿的居中创作区、24px 大圆角输入面板、六个彩色快捷工具和分类密集图库。节点读取成功，截图导出失败，因此当前依据真实节点布局参数实现，图库继续采用明确标注的场景示意素材。

新增内容：图片／视频创作切换；商品引用、素材选择；适用平台；图片清晰度和张数；视频 5／10 秒时长；标准／高质量模型占位选择；独立创作记录页签。商品选择为示例档案，素材选择引用当前本地上传图片。快捷工具填入相应任务描述，未连接实际抠图、翻译或生成服务。

生成记录保存当前参数快照（平台、商品、模型、比例、数量／时长、清晰度），用于后续接入任务 API；图片／视频模型均使用演示能力名称，不沿用旧稿中的未经验证型号与积分报价。原导航与 Agent 功能保持原入口关系。

## 资产导航与独立页面（v3）

「资产」仅为可折叠导航分组，不再进入混合资产页。二级菜单分别为素材库（assets）、商品库（products）、知识库（knowledge），各自进入独立页面，知识库沿用已有服务。移除原素材／商品／知识库页内标签。

视觉参考 Moonclaw web-02，链接节点 38:131168。MasterGo MCP 节点与截图请求均超时，最终通过已打开的 MasterGo 原生客户端确认参考：类型筛选、搜索、网格／列表切换、紧凑无边框文件图标与缩略图、文件名及时间。参考中的临时会话文件 30 天保留说明不直接用于长期商品资产。

素材库 Demo 支持文档、图片、视频、其他类型筛选，名称搜索与排序，批量选择、收藏、本地移除，新建文件夹、上传图片／视频／文档（100MB 上限），本地媒体预览与下载。示例文件明确标识，无法下载虚构原件。用户上传素材支持带入创作面板。商品库独立支持示例商品、新建商品（名称、SKU、卖点）、搜索、收藏与带入创作。两个库切换保留本地数据；整页刷新后清空，未接云端持久化。
