# 商品库：面向内容生产的需求与 Demo 调整

## 目标

商品库为刊登、营销视频、POD 和包装概念提供真实商品资料、明确的 SKU 与参考图，并接收可复用的创作产物。首要任务是让用户知道“当前能做什么、还缺什么、会引用哪些商品事实”。

## 信息架构

- 商品列表：有效商品、待完善资料、参考图、已采用产物统计；搜索、状态筛选和卡片/列表切换。
- 商品详情默认进入「创作概览」，选择目标及 SKU，展示输入要求、缺失资料、预期交付与创作入口。
- SKU 档案、基础资料、参考素材、商品图、其他素材和创作记录保留原有维护能力。
- 创作补充说明：使用场景、定制区域、设计限制；随商品快照进入创作。

## 业务规则

1. 刊登检查名称编码、材质卖点、参考图、SKU 颜色规格和人工核对状态。
2. 视频增加使用场景与人群；POD 增加定制区域和限制；包装概念增加真实尺寸与包装说明。
3. 资料齐备检查不表示质量、法规或平台审核通过。人工确认代表用户对当前商品资料的核对。
4. 概览中的开始按钮需选定一个 SKU、完成该目标的检查且商品未归档。
5. 图片参考范围由 SKU 专属图和商品共用图组成，用户仍需核对共用图。其他 SKU 专属图、已归档参考和未明确设为参考的创作产物不自动引用。
6. 人工核对绑定商品资料快照。商品、SKU 或创作说明变更后需要重新核对；参考图变更仍由当前可用性检查与用户选择控制。
7. 产物统计排除参考素材，按媒体 ID 去重。「已采用」来自现有人工归档状态，不代表真实刊登成功。
8. 包装概念、POD 预览明确标注后续生产要求，Demo 不承诺工厂生产文件或合规结论。

## 已调整的交互

- 列表卡片展示资料状态，支持筛选待完善/已核对资料。
- 创作概览提供刊登套图、商品视频、POD 定制、包装概念四个目标。
- 检查项可直接进入资料编辑、SKU 档案、参考素材或补充说明。
- 核对后将所选 SKU、对应参考图和商品资料带入既有创作工作台，按目标预选工具。
- 商品引用弹窗自动选择单 SKU 商品的规格；切换 SKU 时重新筛选参考图，提交时剔除无效引用。
- 原有导入、资料编辑、素材上传、成果归档与创作快照流程继续复用。

## 边界与后续

当前仍为本地 Demo，商品和补充说明沿用既有 IndexedDB 存储，不新增商品服务、模型调用或生产系统连接。现有浏览器数据无需重置，新字段可为空。

后续需求：逐字段资料来源与确认、参考图角色和校验、SKU 组合任务、品牌规范关联、渠道交付清单、真实审核与刊登回执。上述内容不在本次 Demo 中伪装为已完成能力。

## 验证

- 类型检查、修改文件 ESLint、生产构建。
- 单元测试：SKU 参考范围与产物隔离、归档排除、资料变更后确认失效、按目标补齐输入。
- 浏览器验证：商品库列表、创作概览、SKU 选择、人工核对和套图工作台引用链路。
