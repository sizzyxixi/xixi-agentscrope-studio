# 跨境商品创作 Demo v4

本次仅修改前端，未新增后端接口。新增共享前端状态，统一商品、SKU、素材、商品素材关联、任务快照与创作会话。状态只在当前页面保留，刷新后清空；不同浏览器标签页互不共享。

## 已实现

- 五大图片场景：电商设计、店铺装修、新品开发、POD 开发、智能修图；合计 33 个二级工具和 99 个参数化示例模板。
- 选择工具切换模板与输入要求；探索页按场景、品类、风格、名称、收藏筛选。模板可预览单图或套图结构。
- 商品、SKU 及参考图选择；支持 @ 呼出商品选择器。多规格商品需要明确 SKU；SKU 组合图支持多商品、多 SKU。
- 商品库独立页面：商品档案、SKU、参考素材、商品图、其他素材、创作记录。支持编辑资料、管理 SKU、归档与恢复商品。
- 链接导入：批量链接格式校验，模拟资料读取，预览修改后确认。
- SKU 导入：示例店铺模拟查询；无来源时只创建待完善档案。重复 SKU 匹配已有商品。
- Excel 导入：浏览器解析 XLSX、CSV、TSV，商品编码合并 SKU，校验必填和重复行，下载 CSV 模板与问题清单。5MB、最多 500 行；旧版 XLS 需另存 XLSX。预置「使用示例 XLSX」可直接体验。
- 导入三步流程：来源、预览确认、完成；重复商品可跳过、补充缺失、选择字段更新。
- 创作记录保存商品资料快照、SKU、参考素材、模板、场景工具和输出参数。任务记录不会随商品资料修改而改写。
- 本地创建带 DEMO 标记的 SVG 示意图，可下载、继续对话追加版本、单张重做、整套选择。
- 对话中生成的本地示意图可存入任意商品；来源商品不同时需勾选核对。
- 归档配置商品、SKU、平台、站点、语言、用途、套图、采用状态和存入位置；相同归类重复保存更新关联，不复制媒体文件。不同平台／语言可增加关联。
- 商品图按平台／语言分组，支持筛选、批量采用、修改归类、解除商品关联、下载与来源查看。
- 全局素材库共用同一媒体列表，支持上传、筛选、搜索、收藏、用于创作、图片归档及可恢复的本地回收站。

## 明确边界

- 链接不抓网页，示例店铺不连接真实平台。
- Excel 图片 URL 不自动下载；可在商品详情手动上传参考图。
- 图片为本地 SVG 合成示意，不调用模型，不代表真实工具效果；选择分辨率与比例保存为演示参数。
- 视频模式展示静态分镜占位，不生成真实视频。
- 编辑器专业图层、印刷级文件、真实抠图翻译、模型计费、平台发布、云端持久化均未接入。
- 创作对话是新的创作记录内的本地演示会话；现有 Agent 对话及其后端保持原实现。

## 评审路线

1. 创作首页切换五大场景与二级工具，查看对应模板和专属要求。
2. 商品库 → 导入商品 → Excel 导入 → 使用示例 XLSX，确认同一商品下合并两个 SKU。
3. 商品库 → 商品详情 → 引用商品创作，选择具体 SKU 和参考图。
4. 应用套图模板，设置 Amazon、英语，生成六张演示图。
5. 创作记录 → 继续对话，追加调整图；单张或整套「存入商品」。
6. 查看商品 → 商品图，确认 Amazon／英语分组、SKU、用途和草稿状态。
7. 重复归档同一归类，确认不重复创建关联；切换目标商品时确认归属。
8. 编辑商品卖点后，创作记录中仍显示提交时的历史快照。

## 验证记录

- 类型检查与修改文件 ESLint。
- CSV 引号、逗号及多行文本解析；99 个模板身份唯一；种子 SKU 唯一性。
- 浏览器验证指定 SKU 引用、套图生成、整套归档、商品平台语言分组。
- 浏览器使用内置 XLSX 验证真实解析、两个 SKU 合并、确认导入成功。
- 浏览器自动文件注入受 Chrome 扩展文件 URL 权限限制，未改变浏览器权限；改用内置 XLSX 通过同一解析函数验证。
