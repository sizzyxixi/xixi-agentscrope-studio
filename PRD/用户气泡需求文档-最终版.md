# 用户气泡需求文档

| 文档属性 | 内容 |
|---|---|
| 文档状态 | 最终版 |
| 适用范围 | Agent 会话中的用户消息展示 |
| 关联文档 | Markdown 渲染需求、文件预览需求、图片预览需求、视频播放需求 |

## 1. 需求范围

用户气泡用于展示用户已发送的正文、媒体附件、文件附件和资源引用。

本需求只定义用户气泡需要承载的内容和操作入口，不重复定义 Markdown 渲染、文件预览、图片预览及视频播放的内部规则。

## 2. 消息正文

1. 支持 Markdown 渲染。
2. Markdown 渲染规则以《Markdown 渲染需求》为准。
3. Markdown 渲染失败时，展示原始文本。
4. 正文与附件属于同一条用户消息，并在同一气泡中展示。

## 3. 图片和视频

1. 用户上传的图片和视频在气泡中展示缩略图。
2. 多个图片或视频按照原型中的缩略图列表展示。
3. 点击图片缩略图后打开图片预览。
4. 点击视频缩略图后打开视频播放器。
5. 图片预览交互以《图片预览需求》为准。
6. 视频播放交互以《视频播放需求》为准。
7. 缩略图生成失败时，降级展示为普通文件附件。

## 4. 文件附件

文件附件分为可预览文件和不可预览文件。

| 文件类型 | 气泡展示 | 点击行为 |
|---|---|---|
| 可预览文件 | 文件图标、文件名、文件大小 | 在会话右侧打开文件预览 |
| 压缩包 | 压缩包图标、文件名、文件大小、下载入口 | 不支持在线预览 |
| 文件夹 | 文件夹图标、文件夹名称、下载入口 | 不支持在线预览 |
| 安装包及二进制文件 | 文件图标、文件名、文件大小、下载入口 | 不支持在线预览 |

具体规则如下：

1. 可预览文件点击后，在会话右侧打开文件预览。
2. 文件预览的格式支持、展示方式和异常处理以《文件预览需求》为准。
3. 不支持在线预览的附件必须提供下载入口。
4. 点击不可预览附件的卡片不打开侧边预览。
5. 所有文件附件均展示文件名；存在文件大小时同时展示文件大小。

## 5. 大文本附件

1. 用户复制粘贴的大文本按照 TXT 文件展示。
2. TXT 文件使用普通文本文件附件样式。
3. 点击 TXT 文件后，在会话右侧打开文件预览。
4. TXT 文件提供下载入口。
5. 大文本转换及上传规则以《Chatbox 交互需求文档》为准。

## 6. 资源引用

1. 用户消息包含本地文件或其他资源引用时，在气泡下方展示引用区域。
2. 引用区域展示引用数量和引用项名称。
3. 引用区域支持展开和收起。
4. 文件类引用点击后，根据文件能力打开侧边预览或提供下载。
5. 引用内容的权限、失效和异常规则由资源引用需求定义。

## 7. 消息状态

1. 用户气泡展示消息发送时间。
2. 消息发送中时展示发送中状态。
3. 消息发送失败时展示失败状态和重新发送入口。
4. 消息发送成功后移除过程状态。

## 8. 验收标准

1. 用户正文能够在气泡中完成 Markdown 渲染。
2. 图片和视频能够展示缩略图，并进入对应预览能力。
3. 可预览文件点击后能够在会话右侧打开文件预览。
4. 压缩包、文件夹、安装包和二进制文件不打开在线预览，并提供下载入口。
5. 大文本以 TXT 文件展示，支持侧边预览和下载。
6. 资源引用区域能够正确展示、展开和收起。
7. 消息发送中和发送失败状态能够正确展示。
