# 素材库与商品内容复用需求文档

版本：V2.0  
日期：2026 年 11 月 3 日  
状态：需求评审稿  
适用范围：Web 端素材库、个人空间、企业空间，以及工作台对素材库、商品库、知识库的统一引用。

素材库围绕店铺经营中的商品内容生产提供支持：运营和设计可以复用已有商品图、背景、品牌风格、模特及参考资料，制作新商品内容、修改已有内容，并将可再次使用的结果沉淀下来。素材库承担资源管理与复用入口，商品信息、知识检索和内容生成分别由对应模块承接。

核心业务流程：**确定店铺经营任务 → 选择商品及已有资源 → 生成或修改内容 → 检查并选用结果 → 在后续任务或团队中复用。** 用户可以从任一环节直接进入创作，按任务需要选择已有资源。

## 1 业务背景与产品目标

### 1.1 经营范围

目标市场共 12 个：中国、美国、泰国、印尼、澳洲、马来西亚、菲律宾、越南、欧盟、新西兰、中亚、墨西哥。

目标品类共 8 个：美妆、个护、宠物、服装、玩具、母婴、家具、3C。

素材按个人空间与企业空间统一管理，市场和品类作为经营场景与功能验收的维度。欧盟、中亚的具体经营国家、内容语言及设计要求在任务中确定。

### 1.2 用户与岗位

| 用户岗位 | 经营任务 | 素材库应提供的支持 |
| --- | --- | --- |
| 店铺负责人或兼任运营的经营者 | 确定店铺内容方向、协调上新和活动 | 保存常用风格与素材，方便自己和团队持续复用 |
| 电商运营 | 上新、补图、改图、活动内容、多市场内容适配 | 找到已有商品内容与所需素材，直接带入工作台 |
| 电商设计或美工 | 制作和调整商品图、详情图、活动图及视频素材 | 复用背景、视觉元素、风格参考和历史结果 |
| 企业管理员 | 管理企业共享资源、处理删除与人员变动 | 保障团队素材可维护、删除可控、归属清楚 |

### 1.3 产品目标

1. 减少重复生产：做过的商品图、合适的背景、模特及店铺风格，能够在后续任务继续使用。
2. 降低准备成本：在工作台直接调用已有文件与要求，减少查找、上传和重复描述。
3. 支持持续经营：同一店铺的商品内容可以沿用共同的视觉基调，也允许按商品和任务临时调整。
4. 支持团队协作：成员共同维护和使用企业素材。
5. 保持使用准确：商品事实、视觉参考和知识规则来源清楚，商品与 SKU 对应准确。

### 1.4 需求范围与设计原则

| 类型 | 内容 |
| --- | --- |
| 必需需求 | 个人／企业空间；全部对话生成文件自动归集；企业全员可见可编辑、管理员删除；品牌管理；定制／官方收藏／上传模特；三库统一引用 |
| 体验原则 | 上传即可保存，找到即可引用；系统自动记录文件信息，整理操作按需进行 |
| 规划原则 | 按经营任务设计资源的保存与复用，采用统一素材管理与可选分类 |
| 生命周期 | 已入库素材支持持续查找和复用，容量及商业保存政策另行确定 |

## 2 店铺经营中的复用流程

### 2.1 商品内容生产流程

| 环节 | 用户的实际动作 | 素材库的职责 | 默认体验 |
| --- | --- | --- | --- |
| 明确任务 | 为商品上新、补图、换背景、制作活动图或调整旧内容 | 提供直接创作入口和近期资源 | 从工作台、商品详情或素材详情直接开始 |
| 准备输入 | 选择商品，补充背景、模特、品牌风格或参考资料 | 搜索、预览、引用已有资源 | 按任务选择所需对象 |
| 生成与修改 | 描述目标，生成或修改商品内容 | 提供所选资源并记录来源 | 素材用途优先从对话理解，有歧义时再澄清 |
| 检查与选用 | 检查商品、文案、人物、背景及效果 | 保存结果、展示输入来源，支持继续修改 | 生成结果自动进入历史创作，选用与发布分别操作 |
| 再次复用 | 继续改图、用于下一件商品、给同事使用 | 收藏、加入我的素材、发布企业、关联商品 | 整理与共享均为可选操作，历史产物自动保存 |

通用背景、店铺活动文件等独立任务的交付文件同样进入历史创作。商品与店铺关联按需建立。

### 2.2 三类主要复用关系

| 复用关系 | 例子 | 业务要求 |
| --- | --- | --- |
| 同一商品继续使用 | 找回上次生成的商品图，改文案或换背景 | 直接带入原作品，保留商品与来源关联 |
| 不同商品重复使用 | 多款商品使用同一背景、同一模特或同一店铺风格 | 复用参考资源，目标商品仍使用本次选定的商品信息 |
| 不同成员共同使用 | 设计上传背景，运营自行引用做图 | 企业素材共享可见可编辑，成员可随时查找和使用 |

## 3 用户故事与典型场景

### 3.1 用户故事

| 编号 | 经营任务与用户故事 | 预期行为与结果 |
| --- | --- | --- |
| S01 | 电商运营需要修改之前做过的某款商品图，希望快速找到原图 | 在历史创作按图片、时间或名称查找，预览后直接继续修改 |
| S02 | 电商设计经常使用几张背景，希望换商品时直接调用已有背景 | 上传背景或从历史结果保存到我的素材，后续直接引用 |
| S03 | 精铺店铺需要多款商品保持相近的设计基调，运营希望少重复说明风格 | 按已有资料维护品牌色、风格提示词或参考图，在需要的任务中引用 |
| S04 | 服装运营需要为新款制作上身图，希望选用合适的模特并重复使用 | 从官方收藏、已有上传或定制模特中选择，与本次商品一起引用 |
| S05 | 家具运营需要将商品放入不同房间展示，希望使用已有场景参考 | 引用餐厅、卧室等背景或参考图，结合本次商品制作场景内容 |
| S06 | 运营需要为已有商品制作活动图，希望复用背景和装饰元素 | 在对话中选择已有视觉素材，补充活动要求后生成内容 |
| S07 | 运营需要把已有内容用于另一个市场，希望基于原作品调整 | 找回原作品，明确目标语言或修改要求，形成新结果 |
| S08 | 设计完成一份可复用素材，希望同事能自行找到并使用 | 主动发布到企业空间，或直接上传企业空间，其他成员可查找、编辑和引用 |
| S09 | 企业成员发现素材名称不清楚或有新版本，希望可以直接维护 | 成员直接修改名称、说明或更新内容，保留修改记录 |
| S10 | 企业管理员需要清理错误或无效素材，希望避免普通成员误删 | 管理员删除并可从回收站恢复，普通成员没有企业素材删除权限 |

## 5 信息架构与管理边界

### 5.1 素材库结构

```text
素材库
├─ 个人空间
│  ├─ 历史创作：全部／图片／视频／文件
│  ├─ 我的素材：主动上传或整理为常用的素材
│  ├─ 品牌
│  ├─ 模特：定制／官方／上传
│  └─ 回收站
└─ 企业空间
   ├─ 共享素材
   ├─ 品牌
   ├─ 模特：定制／官方／上传
   └─ 回收站：管理员可操作

工作台 → 引用资产
├─ 素材库：素材／品牌／模特
├─ 商品库：商品／SKU
└─ 知识库：知识库／文档
```

收藏与最近使用提供快捷筛选。背景、场景图、贴纸、纹理、图标、视频片段等统一按图片／视频／文件保存，用户可自行建立文件夹或添加标签。

### 5.2 三库分工

| 管理对象 | 主要维护位置 | 引用时提供的内容 |
| --- | --- | --- |
| 原始商品图、规格和已确认卖点 | 商品库 | 明确的商品、SKU、事实及其参考图 |
| 背景、参考图、视觉元素、视频及其他文件 | 素材库 | 目标文件及本次任务的使用意图 |
| 品牌 | 素材库 | Logo、品牌色、风格提示词及可选参考图 |
| 模特 | 素材库 | 选定人物的参考图、必要描述及可用能力 |
| 活动说明、平台规范、品牌手册等知识资料 | 知识库 | 与当前问题有关的内容和来源 |

商品图或产物可关联已有素材库文件，正式商品图通过选用操作确定。素材文件加入知识库后建立解析记录，解析完成后可供检索。

### 5.3 页面体验原则

默认提供缩略图网格，支持列表查看。常用动作包括预览、引用、下载和收藏；重命名、文件夹和标签放在按需操作中。上传、保存和引用均可直接完成；文件夹、用途说明、品牌和模特按任务需要配置。

## 6 空间与权限

### 6.1 可见范围

个人空间仅本人可见，承载本人历史创作和主动维护的资源。企业空间属于对应企业，全体成员共享可见。成员私有作品、提示词和对话保留在个人范围。

工作台和选择器遵循账号当前身份的空间访问规则。企业身份下本人的私有作品，可以通过发布动作提供给本企业。发布范围为用户选择的资源和共享说明，来源对话保持原有可见范围。

### 6.2 权限矩阵

| 操作 | 个人空间本人 | 企业普通成员 | 企业管理员 |
| --- | --- | --- | --- |
| 查找、预览、下载、引用 | 可以 | 可以，覆盖本企业共享资源 | 可以 |
| 上传素材、创建品牌或模特 | 可以 | 可以 | 可以 |
| 编辑名称、说明、标签、分类 | 可以 | 可以，包括其他成员上传的资源 | 可以 |
| 更新素材内容、品牌和模特信息 | 可以 | 可以，保留修改记录 | 可以 |
| 删除资源及文件夹 | 可以 | 不可以，包括本人上传的企业资源 | 可以 |
| 从回收站恢复、彻底删除 | 可以 | 不可以 | 可以 |
| 读取其他成员个人空间或私有对话 | 不可以 | 不可以 | 仅本人可访问 |

企业上传成功且完成必要校验后即向全员开放。平台维护官方模特原始档案，企业成员维护企业收藏记录的备注。

### 6.3 协作规则

1. 企业素材显示上传人、最近修改人和修改时间；上传者离职后，企业继续保有素材。
2. 替换内容保留版本，已发送任务保留当时使用的内容。
3. 两人同时编辑时提示内容已更新，保留未保存输入，用户确认最新内容后继续保存。
4. 企业资源移出与归属变更操作执行管理员权限校验。取消个人收藏或调整关联只作用于对应记录，原资源继续保留。
5. 删除先进入回收站，可恢复；回收站时长及容量政策另行确定。

## 7 历史创作与通用素材管理

### 7.1 历史创作自动归集

用户在对话过程中成功生成或修改、且已实际交付的所有文件自动进入历史创作。图片、视频分别展示，其他交付文件归入文件分类，包含文档、表格、演示文稿、音频、代码和压缩包等。

用户主动上传到素材库的文件进入我的素材。任务部分成功时，成功交付文件仍应归集。同一文件在消息中重复展示时复用已有入库记录；修改后产生的新内容保留版本或衍生关系。

历史创作默认按交付时间倒序，支持类型、日期和名称查找。系统自动记录可取得的商品关联、来源对话和文件信息。删除来源对话后，已入库作品继续保留并可独立使用。

### 7.2 历史创作中的操作

| 操作 | 行为 |
| --- | --- |
| 预览 | 查看原文件或受支持的预览内容 |
| 继续创作 | 将作品带入指定工作台，结合新要求修改 |
| 下载 | 下载有效原文件 |
| 收藏 | 添加指向原资源的个人快捷标记 |
| 加入我的素材 | 将已有作品加入主动整理视图 |
| 查看来源 | 查看来源任务或对话、商品关联和文件版本 |
| 发布企业 | 在有权的同企业范围内，明确发布所选资源 |
| 删除 | 按所属空间权限操作，说明关联影响 |

历史创作与我的素材展示同一资源时，共享内容和删除状态。“从我的素材移除”只取消该视图关联；“删除文件”需要明确确认实际删除的资源及影响。

### 7.3 上传与编辑

支持点击、多选、拖拽及剪贴板图片上传。用户选择文件后即可上传到当前空间；默认沿用文件名，名称、说明、文件夹和标签均可稍后修改。上传前持续显示目标空间，企业入口说明上传后全员可见可编辑、仅管理员可删除。

批量上传逐项反馈状态，失败项可重试，成功项保留。发起人可取消未完成上传，已发布企业素材的删除由管理员操作。重名文件分别保存；选择更新已有文件时提示形成新版本。

格式、大小和批次数量由支持能力确定并在上传时说明。文件保存、预览和 AI 读取能力分别反馈，各状态按实际处理结果展示。

### 7.4 查找与整理

首期支持文件名、标签和说明关键词搜索，按图片／视频／文件、创建时间筛选，并提供收藏、最近使用和文件夹入口。企业列表可按上传人筛选。商品关联已存在时，可按关联商品查找。

文件夹和标签由用户按需维护。首期采用通用筛选条件，后续根据查找需求扩展。

批量操作覆盖下载、添加标签、加入文件夹；删除仍按权限控制。素材加入文件夹后保留原有共享范围。

### 7.5 背景及其他素材的复用

背景、场景图、装饰元素、纹理、图标等沿用普通素材管理能力。用户可以自行建立常用背景、活动素材等文件夹，也可以只依靠预览和收藏找到它们。

引用背景时允许两种意图：使用原背景，或参考背景生成新场景。使用意图从用户对话理解，必要时给出选择。原图使用与参考生成由创作工具按对应能力执行。

视频片段、音频及设计源文件也按通用素材管理；是否可剪辑、播放或作为生成输入，按当前任务能力单独判断。

## 8 品牌管理

### 8.1 经营用途

品牌模块主要服务需要持续保持视觉基调的店铺。运营或设计将常用 Logo、颜色和风格说明保存后，在多款商品的内容制作中重复使用，减少每次重新上传和描述。

品牌资料按需维护和引用。首期通过名称或说明区分品牌所服务的店铺。

### 8.2 字段与保存

| 字段 | 填写方式 | 使用规则 |
| --- | --- | --- |
| 名称 | 默认生成，可修改 | 用于列表和引用标签，可按品牌或店铺命名 |
| Logo | 可选，上传或从素材中选择 | 可保存多个版本，使用时明确采用哪一份 |
| 品牌色 | 可选，支持多个色值 | 展示色块与色值，供本轮创作采用 |
| 品牌风格提示词 | 可选 | 保存常用的视觉风格、质感、光线或构图要求 |
| 风格参考图 | 可选，从素材库选择 | 提供视觉风格参考，商品外观与事实采用商品资料 |
| 说明 | 可选 | 记录简单补充要求或关联知识资料 |

名称以外至少配置一项可用内容后即可作为品牌资源保存和引用。用户可先保存已有提示词，后续补充 Logo、品牌色等内容。

### 8.3 使用与更新

工作台引用品牌时展示本轮将采用的已填内容。用户可选择本轮采用的 Logo、颜色和风格要求，临时调整仅作用于本次创作。

同一任务默认使用一个主品牌；选入另一品牌时提示替换或明确分别用途。更新品牌后，新任务使用当前内容；已发送任务保留原输入版本。草稿发现品牌更新时提示查看，由用户确认更新本轮要求。

## 9 模特管理

### 9.1 经营用途与三类入口

模特主要用于服装上身、穿搭、试戴、手持或人物使用场景等任务，是否需要由具体商品和内容目标决定。

| 入口 | 用户动作 | 保存与复用方式 |
| --- | --- | --- |
| 官方模特 | 浏览形象，查看详情，收藏或直接使用 | 通过收藏记录再次选择 |
| 上传模特 | 上传有权使用的参考照片，确认人物 | 保存参考图和名称，后续可直接引用 |
| 定制模特 | 选择基础人物特征，生成候选并选定 | 固定选中的人物参考，再用于后续商品内容 |

个人空间的收藏与上传仅本人可见。企业空间添加的模特或官方收藏记录全员可见可用，编辑与删除遵循企业空间权限。

### 9.2 官方模特

以人物预览为主，提供少量常用筛选和详情查看。详情展示可用能力及使用范围。收藏后可以从我的模特中直接选择。

官方模特本身由平台维护。企业成员可编辑企业收藏的备注，移除企业收藏记录按管理员权限处理；各成员及企业收藏分别管理。官方模特停用后保留历史标识，停止新引用。

### 9.3 上传模特

上传入口仅要求选择有效人物照片并确认有权使用。名称默认生成，可稍后修改；额外说明和多角度照片按需补充。

系统提示多人照片、脸部遮挡、模糊等影响使用的问题。保存文件和建立可用人物参考分别反馈；需要额外照片时，说明所需数量与照片要求。企业上传前提示将对企业成员共享。

### 9.4 定制模特

模特管理提供定制、官方、上传三个入口。定制界面采用默认参数和基础选项，其他特征放入高级设置。

![模特创建参考](</Users/sizzy/Documents/AgentScope 研究/PRD/assets/素材库模特创建参考.png>)

流程为：设置必要特征 → 确认预计消耗 → 生成候选 → 预览并选定 → 保存 → 使用。用户选定候选后创建人物档案；关闭弹窗后可从任务记录查看结果。

复用时采用已选人物与参考图。姿势和场景作为本轮任务要求调整，更换人物身份时另存模特。

### 9.5 能力边界

管理入口负责模特保存和选择，换装、视频口播、声音等生产场景按创作能力开放。模特复用效果分别评测人物一致性与商品呈现。

## 10 工作台中的三库引用

### 10.1 入口与选择流程

工作台提供统一的引用资产入口及 `@` 快捷入口，包含素材库、商品库、知识库。素材详情提供引用或继续创作入口；从商品详情开始任务时，自动带入已选商品和 SKU。

选择器支持搜索、预览和多选，显示来源空间、名称与资源类型。素材库内可选择普通素材、品牌和模特；已选内容在切换库时保留。用户确认后插入引用标签，并保留正文与草稿。

选择器展示当前工作范围内有权访问的资源，提供最近使用和收藏快捷入口。

### 10.2 各类输入的作用

| 引用内容 | 为本轮任务提供什么 | 使用时的关键要求 |
| --- | --- | --- |
| 商品与 SKU | 本次商品的真实外观、规格、卖点和对应图片 | 明确本次商品规格，采用对应 SKU 的图片与已确认事实 |
| 背景和其他视觉素材 | 背景原图、构图、场景、风格或装饰元素 | 从对话理解用途；使用原图和参考生成有区别 |
| 历史作品 | 待修改的已有内容 | 明确原作品与新要求，修改结果另存并保留来源关联 |
| 品牌 | 本轮采用的品牌色、Logo、风格等 | 仅带入已配置和本轮采用的内容 |
| 模特 | 本轮人物参考 | 按人物使用范围与工具能力执行任务 |
| 知识库或文档 | 与问题有关的规则、说明和依据 | 反馈解析状态，引用内容可追溯来源 |

用户说“用这张背景给商品换背景”，直接按明确意图处理；用户只选择一张图而意图不清楚时，再询问是修改原图还是参考生成。用户可随时调整本轮用途。

### 10.3 引用标签与有效性

标签显示资源类型、名称和必要的 SKU 信息；点击可预览或移除。移除仅取消本轮引用，原资产继续保留。对象自动带出的图片与用户手动选中的同一文件合并传递；同一文件有多个明确用途时保留这些用途。

发送前检查权限、资源状态、必要解析状态以及当前工具是否支持。失效项定位到具体标签，保留其他输入，替换或移除后可继续。已发送任务保留原输入版本；草稿收到版本变化提示后由用户确认。

知识来源尚未解析、文件无法读取或工具不支持所选视频用途时，应在实际使用前说明。引用复用已有资源，按本轮处理能力和数量限制校验，超限时提示。

### 10.4 商品事实与其他内容的关系

1. 目标商品以本次选定的商品资料及 SKU 为准；背景、模特和风格参考围绕该商品资料生成内容，保持商品尺寸、材质、颜色、数量和已确认卖点准确。
2. 品牌与用户要求发生冲突时，确认本轮临时调整，品牌原档案继续保留。
3. 知识资料有相互冲突的活动时间或规则时，展示冲突来源并由用户确认采用内容。
4. 文档内容作为任务资料处理；修改源资源须按对应操作重新校验权限。

### 10.5 结果沉淀与再次使用

新文件自动归入发起人的历史创作。已选商品产生的内容可自动记录商品关联，但是否成为正式商品图、视频或其他已采用内容，由用户通过选用操作确定，选用前原商品资料继续保留。

用户认为有复用价值时，可收藏、加入我的素材或发布到企业空间。生成结果默认保存在本人历史创作；主动发布时，仅共享所选作品与共享说明。

任务详情提供本轮实际使用的资源与知识来源，便于以后继续修改。所选资源逐项反馈实际使用状态。新任务独立选择输入，继续修改时可沿用相关输入。

### 10.6 三个端到端示例

**服装上新。** 运营从商品库选中连衣裙及颜色规格，引用已有模特和棚拍背景，要求生成上身图。结果自动进入历史创作并记录商品关联；满意后选作商品素材，下一款衣服继续使用该模特和背景。品牌仅在有风格要求时引用。

**家具补图。** 运营找回餐桌历史作品，选择已有餐厅场景图，提出保留商品、改变场景的要求。结果保留与原作品的关联，后续可继续修改。

**精铺活动内容。** 运营选择商品、已有品牌风格和常用背景，引用知识库中的活动说明制作活动图。下一款商品可以沿用品牌与背景，但重新选择商品；换目标市场时，在任务中指定语言和修改要求，基于已有资源产生新内容。

## 11 异常与空状态

| 状态或场景 | 体验要求 |
| --- | --- |
| 历史创作为空 | 说明生成文件会自动保存，提供直接开始创作入口 |
| 我的素材或企业共享素材为空 | 提供上传入口；企业入口展示共享与删除规则 |
| 品牌或模特为空 | 提供创建／选择入口，支持按任务需要添加 |
| 搜索无结果 | 可清空筛选、查看最近使用或直接上传 |
| 上传失败 | 逐项重试，保留成功项和其他输入 |
| 文件无法预览 | 展示类型和信息，原文件有效时保留下载 |
| 文件可保存但当前任务无法读取 | 说明当前读取限制，提供更换文件或调整用途的入口 |
| 知识解析中或失败 | 显示解析状态及可用操作 |
| 引用被删除或权限变化 | 标签标记失效，由用户替换或移除失效项 |
| 普通成员尝试删除企业资源 | 删除入口仅管理员可见，服务端校验管理员权限 |
| 资源更新或并发修改 | 显示版本变化，保留用户草稿，确认最新版本后继续保存 |
| 自动归集失败 | 显示待保存或保存失败，支持重试；取得原文件并完成入库后显示保存成功 |
| 容量不足 | 说明对应空间及受影响操作，在上传或生成前校验容量，结果保存异常时保留处理入口 |
| 账号身份或企业切换 | 刷新可访问资源，按新范围重新校验引用 |

生成成功与保存成功分别反馈。容量不足时是否允许继续生成、兜底方式和时长在容量政策中确定，并向用户展示明确的处理规则。

## 12 首期范围与后续增强

### 12.1 首期交付

| 模块 | 首期必需能力 |
| --- | --- |
| 空间 | 个人与企业空间；全员共享编辑、管理员删除；明确归属与回收站 |
| 历史创作 | 所有已交付文件自动归集；图片／视频／文件分类；来源、预览、下载和继续创作 |
| 通用素材 | 上传、重命名、文件夹、可选标签、搜索、收藏、最近使用、基础批量操作、更新记录 |
| 品牌 | 可按现有资料创建；Logo、品牌色、风格提示词、参考图；按需引用与更新 |
| 模特 | 官方查看收藏、上传、定制候选选定保存、后续引用 |
| 三库引用 | 统一入口；多选、预览和引用标签；商品／SKU、品牌、模特、普通素材和知识来源 |
| 结果复用 | 自动保存，关联商品，用户选用与主动共享；历史任务输入可追溯 |

模特定制和复用需要独立验证实际生成能力。首期开放经验证的场景，详情展示支持范围，后续使用固定选定的人物参考。

### 12.2 后续按需求增加

后续可评估语义搜索、自动标签建议、相似素材查找、更完整版本浏览、多角度模特管理和更多生产能力。只有用户确实因素材量增长遇到查找困难时，再评估市场、品类等更细筛选。

### 12.3 设计验证顺序

先验证商品内容生产中的三条闭环：服装上新、家具补图、精铺活动内容。再用其他品类检查通用管理是否可用。验收覆盖至少两种目标市场内容任务，检查在统一素材库中跨任务复用资源的完成情况。

原型需要覆盖素材列表与详情、历史创作、上传、品牌创建、模特三入口与选定结果、工作台统一引用、企业编辑与管理员删除。

## 14 产品指标与研究验证

### 14.1 观察指标

| 指标 | 定义与用途 |
| --- | --- |
| 旧内容查找成功率与耗时 | 在真实补图或改图任务中能否找到指定历史文件，观察节省的查找步骤 |
| 资源复用率 | 观察期内在不同任务使用的资源比例，按背景、品牌、模特和其他素材拆分 |
| 企业协作使用 | 共享素材被上传者之外成员使用的情况，验证是否减少团队索取文件 |
| 重复准备成本 | 比较同类任务的重复上传次数、重复风格说明和输入准备耗时 |
| 自动归集与引用成功率 | 分别统计保存失败、权限失效、格式不支持及读取失败，与生成效果分别统计 |
| 内容选用情况 | 观察复用输入的结果是否被用户选用，按经营任务分析，分别记录保存与选用状态 |

首期建立真实基线后确定业务目标值。素材管理效果、输入引用正确性、生成质量分别评价。

### 14.2 用户研究

访谈覆盖店铺负责人、电商运营、设计／美工及管理员，以最近一次上新、补图或活动内容任务为例，观察文件从哪里找、哪些内容会重复用、是否要找同事、在哪一步重新上传和说明。

原型测试覆盖上传背景、找回旧图、收藏模特、保存部分品牌资料和三库引用，观察独立完成率、填写步骤和页面跳转次数。

| 事项 | 需要确定的结果 |
