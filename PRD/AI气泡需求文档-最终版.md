# AI 气泡需求文档

| 文档属性 | 内容 |
|---|---|
| 文档状态 | 最终版 |
| 适用范围 | Agent 会话中的 AI 回复展示 |
| 关联文档 | Markdown 渲染需求、文件预览需求、图片预览需求、视频播放需求、分享需求、会话分支需求、积分需求 |

## 1. 气泡组成

AI 气泡由以下部分组成：

1. 思考过程。
2. 回复正文。
3. 文件产物。
4. 消息操作。
5. 消息完成时间。
6. 积分消耗。

没有对应内容的区域不展示。

## 2. 回复正文

1. AI 回复正文支持流式输出。
2. 正文使用 Markdown 渲染。
3. Markdown 内容支持常规文本、标题、列表、引用、表格、代码块、流程图和链接。
4. Markdown 的具体解析和展示规则以《Markdown 渲染需求》为准。
5. 流式输出过程中持续追加内容，不重复刷新整个气泡。
6. Markdown 渲染失败时，降级展示原始文本。
7. 用户主动向上滚动后停止自动跟随，并提供“回到最新”入口。

## 3. 思考过程

### 3.1 展示状态

| 状态 | 展示内容 |
|---|---|
| 思考中 | “思考中”状态和实时计时 |
| 已完成 | “思考已完成”和本次思考耗时 |

### 3.2 计时规则

1. Agent 进入思考阶段时开始计时。
2. 思考中按秒更新计时，格式为 `思考中 · 12秒`。
3. 超过 60 秒后使用分秒格式，例如 `思考中 · 1分08秒`。
4. 思考结束后停止计时，并展示最终耗时，例如 `思考已完成 · 18秒`。
5. 页面刷新或重新进入会话后，使用服务端记录的开始和结束时间还原耗时。

### 3.3 折叠内容

1. 思考过程默认折叠。
2. 用户点击思考状态区域后展开或收起思考内容。
3. 思考中展开时，内容随执行过程持续更新。
4. 思考完成后保留最终内容，用户仍可展开查看。
5. 展开的内容仅包含允许向用户公开的思考摘要或过程记录，不展示模型内部原始思维链。
6. 没有可公开思考内容时，只展示状态和耗时，不提供展开入口。

## 4. 文件产物

AI 生成的图片、视频、普通文件和文件夹均作为当前回复的文件产物展示。

| 产物类型 | 展示与操作 |
|---|---|
| 图片 | 展示缩略图；支持图片预览和下载 |
| 视频 | 展示视频封面；支持在线播放和下载 |
| 可预览文件 | 展示文件卡片；点击后在会话右侧预览；支持下载 |
| 不可预览文件 | 展示文件卡片；仅提供下载 |
| 文件夹 | 展示文件夹卡片；提供下载 |

其他规则：

1. 多个文件产物按照生成完成时间正序排列。
2. 文件卡片展示文件名、文件类型和文件大小。
3. 文件预览、图片查看和视频播放的具体规则以对应专项需求为准。
4. 文件失效时保留文件卡片，并展示失效状态。
5. 文件生成失败时不展示无效文件卡片，失败信息由 Agent 会话过程展示。

## 5. 消息操作

| 操作 | 规则 |
|---|---|
| 复制 | 复制 AI 回复正文，不包含思考过程、文件产物、时间和积分信息 |
| 分享 | 创建该条 AI 回复的分享内容，具体规则以《分享需求》为准 |
| 创建新分支 | 以该条 AI 回复为分支起点创建新会话分支 |
| 点赞 | 对当前 AI 回复提交正向反馈 |
| 点踩 | 对当前 AI 回复提交负向反馈 |

操作入口在 AI 回复完成后展示。

补充规则：

1. 点赞和点踩互斥。
2. 再次点击当前反馈可取消反馈。
3. 创建新分支后，原会话和原消息不发生变化。
4. 分享和创建新分支失败时，在当前气泡附近展示失败提示。

## 6. 消息完成时间

1. AI 回复完成后展示消息完成时间。
2. 时间使用服务端记录的 `completedAt`。
3. 时间按用户当前时区转换，精确到分钟，不展示秒。
4. 时间格式与用户气泡的消息时间规则一致。
5. AI 仍在输出时不展示完成时间。
6. 输出停止或失败时不生成完成时间。

## 7. 积分消耗

1. 当轮计费执行结束并完成积分结算后，展示当轮对话实际消耗的积分；回复文本结束不代表后台执行已经结束。
2. 积分包含当前一轮中模型、工具调用、文件处理和执行环境产生的全部用户可计费消耗；已包含在工具价格中的费用不重复计入。
3. 积分只展示当轮合计值，格式为 `消耗 N 积分`。
4. 积分结算完成前不展示预估值。回复文本已结束但后台任务未完成，或最终结算尚在处理时，在积分区域展示 `积分结算中`。
5. 正常完成、主动停止和执行失败均按实际已发生的消耗进行结算和展示。
6. 积分明细和通用计费规则以《积分需求》为准；沙箱执行、异步轮次及统一扣减按 [《沙箱按量执行与轮次积分结算 PRD》](沙箱按量执行与轮次积分结算PRD-最终版.md) 执行。

## 8. 展示顺序

AI 气泡内容按照以下顺序展示：

1. 思考过程。
2. 回复正文。
3. 文件产物。
4. 消息操作。
5. 消息完成时间和积分消耗。

消息完成时间和积分消耗在同一信息区域展示。

## 10. 验收标准

1. AI 正文能够流式输出并完成 Markdown 渲染。
2. 表格、代码块、流程图和链接能够通过 Markdown 渲染能力展示。
3. 思考中展示实时计时，完成后展示最终耗时。
4. 思考过程默认折叠，并可展开查看公开的思考摘要。
5. 图片、视频、文件和文件夹产物能够展示对应操作入口。
6. AI 回复完成后展示复制、分享、创建新分支、点赞和点踩操作。
7. AI 回复完成后展示服务端记录的完成时间。
8. 积分结算完成后展示当轮实际消耗积分。
9. 复制正文时不包含思考过程、文件产物、时间和积分信息。
