# 文件预览及操作 PRD

版本：V1.0  
适用端：网页端（Web）  
适用范围：当前会话的上传文件、AI 文件产物及文件预览

## 1. 文件的可见位置

### 1.1 预览入口

用户气泡、AI 气泡的文件产物和侧边栏文件列表均提供文件预览入口，同一文件的不同入口关联同一文件标识。

|位置|文件展示|点击行为|
|---|---|---|
|用户气泡|图片、视频缩略图，正文中的文件引用，下方折叠文件区|图片打开图片预览，视频打开播放器，普通文件打开侧边预览|
|AI 气泡的文件产物|本轮成功生成或修改的文件卡片、图片缩略图及视频封面|图片打开图片预览，视频打开播放器，普通文件打开侧边预览|
|侧边栏—文件列表|当前会话中成功交付的 AI 文件产物|点击文件打开对应侧边预览；HTML 使用内置浏览器打开|

补充规则：

1. 正文中的文件引用与文件卡片使用相同的预览能力及访问权限。
2. 普通文件均可进入侧边预览，支持格式显示内容，其他格式显示缺省页及下载入口。
3. 文件夹打开文件信息及目录展示；图片和视频具体查看方式由对应媒体需求承接。
4. 输入框附件区沿用《附件上传需求文档》的操作，文件生成与消息布局分别沿用对应需求。

### 1.2 文件列表

侧边栏文件列表的展示范围、列表与缩略图切换、字段、排序及空状态，由 [侧边栏需求文档，第 3 章](<侧边栏需求文档.md>) 定义。文件预览及引用、删除、下载、刷新按本需求执行。

## 2. 支持预览的文件类型清单

### 2.1 类型与预览方式

|类型及格式|预览方式与边界|候选实现|
|---|---|---|
|文本及代码：txt、log、json、jsonl、ndjson、yaml、yml、xml；js、ts、py、sql 等常见代码|文本预览及语法高亮；格式化仅改变视图；超量截断并提示|CodeMirror|
|Markdown：md、markdown|渲染与原文切换|markdown-it 与清洗器|
|HTML：html、htm|在内置浏览器中展示页面，使用隔离环境|隔离页面容器|
|PDF：pdf|翻页、缩放，有文字层时支持搜索；扫描件搜索依赖 OCR|PDF.js|
|图片：png、jpg、jpeg、webp、gif|缩放、拖动，GIF 可播放；超大图使用预览副本|浏览器图片组件|
|SVG：svg|安全处理后生成 PNG，失败时展示转义后的源码|隔离 SVG 渲染器|
|文本表格：csv、tsv|只读数据表，横纵滚动；处理编码和分隔符，超量分页或抽样并提示|解析器与表格组件|
|Excel：xlsx|只读、多工作表切换，优先显示缓存值；缺少结果时显示公式及“未计算”|SheetJS CE 与表格组件|
|Word：docx|基础只读布局，复杂排版可能变化|docx-preview，PDF 预览可选|
|演示文稿：pptx|转换为静态 PDF 后预览，动画及交互按静态内容处理|LibreOffice 与 PDF.js|
|音频：mp3、wav、m4a、aac、flac、ogg、opus、weba|按已部署播放器及浏览器解码能力播放，无法播放时提供下载|浏览器播放器及音频处理服务|
|视频：mp4、mov、webm、mkv、m4v、ogv、avi、mpeg、mpg|按已部署播放器及转码能力播放，无法播放时提供下载；封面可由 FFmpeg 提取|浏览器播放器与 FFmpeg|
|文件夹|展示名称、文件数量及目录信息，提供 ZIP 下载|目录信息与打包服务|

上传白名单与预览能力分别管理。音视频的扩展名相同也可能使用不同编码，播放结果按实际解码或转码能力判断。

### 2.2 预览降级

- ZIP、PSD、RAW、CR2、旧版 doc、ppt、xls 及其他未接入预览的格式，显示缺省页并提供下载。
- 特殊图片已有预览副本时复用该副本；实际转换成功后可按图片展示。
- Office 复杂排版、XLSX 图表和复杂样式按当前工具能力展示；预览失败时保留有效原文件的下载。
- 超过预览处理量时分页、抽样或截断，并标明显示范围；具体阈值在对应能力建设时明确。

### 2.3 内容处理

1. Markdown 内容经过清洗，链接使用受支持协议；远程资源按授权加载策略处理。
2. HTML 在与主应用隔离的环境中展示，同目录资源通过文件授权加载；页面脚本按已部署隔离能力执行。
3. 表格按数据读取，CSV 字段按文本展示，XLSX 宏及其他文件脚本按资料处理。
4. 预览副本与原文件分别保存，预览处理保持原文件内容。

候选组件需经过部署及兼容性验证。参考：[PDF.js](https://mozilla.github.io/pdf.js/)、[docx-preview](https://github.com/VolodymyrBaydalka/docxjs)、[Markdown 安全策略](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md)、[HTML 隔离说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。

## 3. 侧边预览文件

### 3.1 打开与展示

1. 预览顶部展示文件名、文件信息和刷新、引用、下载操作，并提供关闭入口。
2. 同一文件再次打开时复用已有预览；点击其他文件切换内容，关闭预览后会话及输入框保持原样。
3. 预览为只读展示，内容修改通过 AI 会话指令执行。
4. 加载中显示加载动效，成功后显示内容；不支持预览时显示缺省页及下载入口。
5. 刷新页面后恢复已保存的预览目标，重新检查权限和文件版本。

### 3.2 文件内容更新

1. 同一文件编辑成功后，更新文件版本及更新时间，后续打开指向最新成功内容。
2. 用户已打开的预览保持当前内容；再次点击文件入口、重新打开或点击刷新时检查最新版本。
3. 文件版本变化时重新加载，版本相同时继续使用缓存；手动刷新重新请求最新可用内容。
4. 历史入口按文件标识定位；重命名或移动后，由文件服务更新记录，继续访问同一文件。
5. 历史消息可保留发送时的文件名，预览标题使用当前文件名。

### 3.3 文件过期或找不到

|场景|处理规则|
|---|---|
|文件过期|保留历史卡片，预览显示统一文件提示，引用和下载停止本次操作|
|文件已删除|历史卡片保留，预览显示统一文件提示，文件列表及 @ 下拉移除该项|
|文件找不到且原因未明确|显示统一文件提示，保留历史记录|
|无访问权限|显示统一文件提示，结束预览、引用或下载|
|文件加载失败|显示统一文件提示；原文件仍可访问时提供下载|

补充规则：

- 上传文件沿用上传成功起算的 30 天有效期；AI 产物从首次成功交付起算 30 天。
- 文件更新、预览、引用及下载沿用原有效期；另存的新文件重新起算。
- 超过 30 天转入深度存储，访问失效；运行环境清理后，有效 OSS 文件仍可取得。
- 用户要求 AI 读取历史文件时，AI 根据文件记录识别目标；确认过期时说明已过期，原因不明时说明可能已过期，并提示重新上传。
- 会话删除、分享和分支涉及的文件权限按专项规则处理。

### 3.4 文件提示

暂不支持预览、加载失败、文件过期、已删除、找不到或无访问权限时，统一展示一条提示：

|中文|English|
|---|---|
|文件暂无法查看。|File unavailable.|

系统仍按实际状态控制操作：文件有效且有权限时保留下载；过期、已删除或无权限时结束预览、引用及下载。

预览内容截断与公式未计算属于内容说明，分别显示“仅展示部分内容”和“未计算”。

## 4. 文件操作

### 4.1 引用

1. 文件列表及预览区域提供“引用”入口，在输入框当前光标位置插入文件引用标签；无有效光标位置时插入末尾。
2. 输入 `@` 打开引用下拉，可搜索文件名；上下键移动选择，Enter 插入，Esc 关闭。
3. 下拉包含当前输入框已上传完成文件、当前会话历史上传文件及 AI 产物，按更新时间倒序排列。引用下拉与侧边栏文件列表分别使用各自的展示范围，排序方式一致。
4. 仅展示有权限、未过期且未删除的文件，同一文件展示一项，文件夹作为一个资源。
5. 引用标签展示文件名，内部关联文件标识，参与本轮任务上下文；发送时检查权限、有效期及最新版本。
6. 支持重复引用；引用复用原文件，不重新上传、不新增附件卡片、不占新增上传名额。
7. 删除引用标签只取消该处引用；移除草稿附件时同步清理对应引用，删除文件后对应引用标记失效。
8. 输入框附件右键引用沿用《附件上传需求文档》，引用结果保持一致。

### 4.2 删除

1. 有删除权限的文件项提供入口，删除前检查文件标识、存在状态及权限。
2. 文件可删除时弹出二次确认，取消后保持原样。
3. 确认后再次检查权限及版本，文件已更新时提示重新确认。
4. 成功后撤销访问，清理 OSS 原文件、预览及运行环境副本，实际清理按存储流程执行。
5. 文件列表和 @ 下拉移除该项，已有预览显示统一文件提示；当前草稿引用标记失效，用户移除后可继续发送。
6. 历史消息保留卡片，点击显示统一文件提示；普通正文保持原样。
7. 文件不存在、无权限或删除失败时显示对应提示。
8. 本期提供文件删除，文件夹整体删除由目录管理能力另行定义。

删除是网页发起的服务端操作，作用于系统保存的文件及副本。

### 4.3 下载

1. 文件列表、预览区域及 AI 产物卡片提供下载，操作前检查权限和有效期。
2. 下载原格式文件；文件夹下载为保留目录结构的 ZIP，ZIP 文件直接下载。
3. 下载取得最新成功版本；与当前预览版本不同时提示“文件已更新，下载的是最新版本”。
4. 下载请求失败时保留入口并提示；文件过期、删除或无权限时使用统一文件提示。

### 4.4 刷新

1. 侧边预览提供刷新按钮，重新检查权限、有效期及版本，并请求最新文件内容。
2. 刷新期间显示加载动效，当前会话与输入框保持原样。
3. 刷新成功展示最新内容；无法访问或预览文件时，显示统一文件提示。

### 4.6 验收标准

1. 用户上传文件从用户气泡进入预览，AI 产物从 AI 气泡或侧边栏文件列表进入预览；文件列表仅展示 AI 产物，文件引用与卡片定位一致。
2. 支持类型按清单展示，其他格式显示缺省页，音视频按实际解码能力播放。
3. 文件更新后当前预览保持原样，再次打开或刷新取得最新版本。
4. 重命名及移动更新文件记录；预览异常统一显示“文件暂无法查看。”，操作权限按实际状态控制。
5. 引用和 @ 搜索、键盘操作正确，重复引用不增加上传名额，发送前检查文件。
6. 删除二次确认、版本检查、列表更新及草稿引用失效正确，取消和失败保持原内容。
7. 下载提供最新原文件，文件夹 ZIP 保留结构，失效文件停止访问。
8. 刷新及运行环境清理后仍可取得有效 OSS 文件，所有入口使用统一有效期。
9. HTML、Markdown、SVG 及表格按已部署内容处理规则展示，原件保持原样。
