# 素材库与统一资产引用需求文档

版本：V5.4  
更新日期：2026 年 11 月 5 日  

## 1 功能范围

本需求覆盖店铺商品内容生产中的历史文件复用、个人及企业素材管理、风格管理、模特管理及创作聊天框中的资产引用。

| 模块 | 适用范围 | 主要场景 |
| --- | --- | --- |
| 资源归属 | 个人资产／企业资产 | 区分本人私有资源与当前企业共享资源，按归属确定访问及维护权限 |
| 创作历史 | 本人已交付的生成及编辑结果 | 找回历史作品，继续修改、收藏或发布 |
| 素材 | 个人与企业文件及一级文件夹 | 维护常用背景、参考图、视频及文件 |
| 风格 | 个人与企业风格方案 | 复用店铺基调、系列风格或活动视觉 |
| 模特 | 个人自建及官方收藏、企业自建模特 | 商品上身、人物出镜及使用场景制作 |
| 创作资产引用 | 本人及企业可访问资源 | 将文件、风格或模特带入创作聊天框，并作为 AI 输入 |
| 回收站 | 删除后 7 天内可按权限恢复的资源 | 恢复误删文件、风格和自建模特，到期自动销毁 |

## 2 创作历史

### 2.1 归集与有效性

归集本人在对话中已交付的生成、编辑结果，包括图片、视频、文档及其他文件。每个文件记录唯一标识、名称、内容地址、类型、大小、归属人、来源任务、创建时间、更新时间、收藏及删除状态。

- 已交付文件按文件标识去重，记录来源任务及创建时间。
- 用户上传的创作输入文件按上传素材管理，不计为生成结果。
- 未交付结果不进入可下载、可引用的历史文件集合。
- 查询历史时排除已删除及超过 365 天的记录；收藏文件到期后仍可通过个人素材使用。
- 历史固定按创建时间倒序查询，不支持用户调整排序方式。

### 2.2 文件分类

| 分类 | 判断范围 |
| --- | --- |
| 全部 | 当前查询范围内图片、视频、文档、其他四类有效文件的并集 |
| 图片 | PNG、JPG／JPEG、WebP、GIF、SVG、HEIC／HEIF、BMP、TIFF，以及 PSD、RAW、CR2 等图像源文件 |
| 视频 | MP4、MOV 及已识别的视频媒体类型 |
| 文档 | 文本、日志、结构化数据、代码、Markdown、PDF、表格及 Office 文档，具体格式见下表 |
| 其他 | 音频、ZIP 等压缩文件、DMG／PKG／APP／EXE 等安装或应用文件、未知格式及其余文件 |

归入“文档”的格式：

| 文档类型 | 扩展名 |
| --- | --- |
| 文本、日志与结构化数据 | txt、log、json、yaml、yml、xml |
| 代码及脚本 | js、ts、tsx、jsx、py、java、go、css、html、sh、sql 等已识别的文本代码格式 |
| Markdown | md、markdown |
| PDF | pdf |
| 分隔值表格 | csv、tsv |
| Office | xlsx、docx、pptx、doc、ppt、xls |
| 其他已识别文档 | rtf、odt、ods、odp 等 |

扩展名识别不区分大小写，结合文件媒体类型确认资源类型。每个文件只归入一个分类，“全部”结果不遗漏、不重复。JSON、LOG、代码及脚本文件归入文档，不归入其他。

分类与打开方式分别判断：例如 XLSX 可在线只读预览，DOC／PPT／XLS 使用本机应用；SVG 转 PNG 失败时查看源码，分类仍为图片。完整打开规则见 3.6。

### 2.3 查询、搜索与分页

| 项目 | 规则 |
| --- | --- |
| 查询范围 | 本人有效历史文件 |
| 搜索字段 | 文件名称、说明、标签、关联商品名称 |
| 匹配方式 | 不区分大小写的包含匹配，搜索与文件类型条件共同生效 |
| 排序 | 创建时间倒序；创建时间相同时按文件标识保持稳定顺序 |
| 分页 | 默认每页 20 项，支持 10／20／50 项及指定页码查询 |
| 结果总数 | 当前授权范围内符合查询条件的有效文件数量 |
| 条件变更 | 类型、关键词、每页数量变化后从第一页重新查询 |
| 结果减少 | 当前页超出有效页码时，回到最后一个有效页 |

翻页、切换资源范围或变更查询条件后清空批量选择。改变文件查看方式不改变查询条件和选择结果。

### 2.4 单文件操作

#### 2.4.1 文件打开与预览

用户点击文件名称或缩略内容后，按扩展名执行以下打开行为：

| 文件范围 | 打开行为 | 功能要求 |
| --- | --- | --- |
| 文本、代码、MD、PDF、CSV／TSV、XLSX、DOCX | 使用侧边栏只读阅读器打开 | 文本代码高亮及格式化；MD 渲染／原文切换；PDF 翻页、缩放、搜索；表格按结构解析 |
| PPTX | 转为 PDF 后在侧边栏打开 | 支持 PDF 翻页、缩放及搜索；转换不改变原 PPTX 文件 |
| PNG、JPG／JPEG、WebP、GIF | 在会话中或侧边栏打开图片预览 | 缩放、拖动查看；GIF 保持动画播放 |
| SVG、HEIC／HEIF、BMP、TIFF | 转为 PNG 后在侧边栏预览 | SVG 转换失败时查看只读源码；其他格式转换失败时允许下载原文件 |
| MP4、MOV | 新窗口打开浏览器原生播放器 | 播放、暂停、拖动进度、查看时长 |
| ZIP、PSD、RAW、CR2、DOC、PPT、XLS、安装文件及未知格式等 | 定位文件所在目录，由用户使用本机默认应用打开 | 不提供内置预览；未下载文件先下载，完成后定位，具体行为见 3.6.3 |

打开方式、阅读能力和阅读器选型以 3.6 的格式表为准。所有侧边栏文档内容只读，不通过预览修改原文件。

文件已删除或无访问权限时，不读取或转换原件，提示“文件已失效或无访问权限，请刷新后重试。”。加载或转换失败时按 3.6 的格式降级规则处理，保留下载有效原文件的能力。

关闭预览后保留原查询、分类、页码和选择状态。支持同类文件切换时，仅在当前查询结果中切换。

#### 2.4.2 引用

1. 用户点击“引用”，跳转至创作工作台的聊天输入框，将该文件作为附件加入。
2. 聊天框已有文字及其他引用保持不变，不自动发送消息。用户继续输入创作要求后自行发送。
3. 同一文件已在聊天框中时，不重复添加，提示“该素材已引用”。
4. 普通文件附件去重后最多 20 个；已满 20 个时，不新增文件，提示“最多引用 20 个文件，请先移除部分附件。”。
5. 文件已删除、历史文件已到期且未收藏，或用户已无访问权限时，不带入文件，提示“该素材已失效或无访问权限，请重新选择。”。
6. 不支持在线预览的文件仍可作为附件加入。生成模型能否读取该格式，在用户发送创作要求时检查；不支持时说明具体文件和格式，保留用户输入供调整。

#### 2.4.3 下载

点击“下载”后下载原文件，文件名采用当前保存的名称，扩展名与原文件格式一致；图片不下载缩略图，视频不下载封面。

下载不改变文件归属、收藏状态和保留时间。重复点击不改变资源记录。读取失败提示“下载失败，请重试。”；文件失效或权限不足时停止下载并提示原因。

#### 2.4.4 收藏至素材

1. 点击“收藏至素材”，将文件加入“素材—我的”的根目录，个人素材永久保存该文件。
2. 创作历史中的原文件继续保留，原创建时间及 365 天有效期不变。
3. 收藏使用同一文件标识，历史与个人素材共用文件内容、名称、标签及删除状态。
4. 成功提示“已收藏至素材，永久保存。”；重复收藏不生成新文件，提示“已收藏至素材”。
5. 文件已删除或历史未收藏文件已到期时，收藏失败，提示“该文件已失效，无法收藏。”。
6. 收藏后用户可在素材中移动文件夹或重命名；这些修改同步作用于同一历史文件。

#### 2.4.5 发布至企业空间

用户**当前使用的身份必须为企业身份，且是该企业的有效成员**。仅账号加入过企业、但当前使用个人身份，不满足发布条件；个人身份不提供发布操作，执行请求时仍应校验并提示“请切换至企业身份后发布。”。

1. 用户发起发布后选择当前企业的根目录或一个有效文件夹；默认根目录。
2. 确认后创建企业文件副本，个人原件保留；企业副本的责任人为发布人，其他企业成员可以查看和引用。
3. 成功提示“已发布至企业空间”；取消或关闭本次发布不创建文件。
4. 同一源文件在同一企业中已有未删除副本时，**不重复发布、不覆盖、不改变已有副本的目录**，提示“该素材已发布至企业空间，请前往企业共享查看。”。
5. 已有企业副本已移入回收站时，允许再次发布，创建新副本，原回收站记录保留；如恢复旧副本，同一企业已有该源文件的有效副本时不再恢复，提示“企业空间已有该素材，无需重复恢复。”。
6. 不同企业分别判断是否已发布。用户只能向当前企业发布，不能在本次操作中指定其他企业。
7. 原件重命名、移动、收藏及删除不改变已发布副本；个人原件修改后重复发布也不覆盖企业内容。
8. 目标文件夹失效时保留发布选择，提示“目标文件夹已不存在，请重新选择。”；源文件失效或成员身份失效时终止发布并说明原因。

重复发布按“源资源标识＋企业标识＋未删除状态”判断，同名或同内容但源标识不同的文件分别处理；同一次确认的重试也不得产生重复副本。

#### 2.4.6 删除

点击“删除”必须二次确认，确认前不修改文件状态。

| 项目 | 文案或行为 |
| --- | --- |
| 确认标题 | 删除该文件？ |
| 未收藏历史文件的说明 | 删除后在回收站保留 7 天，到期自动销毁。 |
| 已收藏历史文件的说明 | 该文件将从创作历史和我的素材中同时移除，在回收站保留 7 天，到期自动销毁。 |
| 确认操作 | 删除 |
| 取消操作 | 取消；关闭确认也视为取消 |

确认删除后：

- 将该文件标记为已删除并记录删除时间，移入个人回收站，不立即销毁原文件。
- 创作历史、个人素材和可引用资源中不再返回该文件；若尚未发送的聊天输入框已引用该文件，同步移除该引用。
- 保留原文件内容、名称、目录关系和收藏状态，供恢复使用；恢复规则见 8.1。
- 该文件已发布的企业副本保留，不受个人删除影响。
- 成功提示“已移入回收站，7 天内可恢复。”；失败提示“删除失败，请重试。”，不清除未成功删除的资源。
- 重复删除已在回收站的文件，不新增回收站记录，提示“该文件已在回收站”。

### 2.5 批量操作

批量选择只针对当前查询页，支持逐项选择、取消、全选当前页及同页连续范围选择。没有选中文件时，不能执行批量动作。

| 功能 | 具体处理 |
| --- | --- |
| 批量下载 | 只选一个时下载原文件；选择多个时打包下载。任一原件读取失败时不生成不完整压缩包，说明失败文件，保留选择供重试 |
| 批量删除 | 二次确认标题“删除所选 {{count}} 个文件？”，说明“删除后在回收站保留 7 天，到期自动销毁。已收藏文件也会从我的素材中移除。”；确认后全部移入回收站，成功提示“已删除 {{count}} 个文件，7 天内可在回收站恢复。” |
| 批量收藏 | 未收藏项加入个人素材根目录，已收藏项跳过；成功说明本次新增数及已收藏数，保留原历史记录 |
| 批量引用 | 去重后计算聊天框附件合计数，不超过 20 个时一起加入创作聊天框并跳转，不自动发送；超限时整批不加入，提示需减少的数量，保留原选择 |

执行前再次检查所选文件是否存在、是否已删除及是否仍有操作权限；出现无效项时整批不执行，说明具体文件，允许用户取消这些文件后重试。

退出批量操作、翻页或改变查询条件时清空选择；手动退出保留当前搜索、分类和页码。批量引用成功后结束本次批量选择。

### 2.6 权限

创作历史仅本人可查询、预览、下载、引用、收藏、发布和删除；管理员身份不扩大他人个人历史的访问范围。

发布操作另需满足 2.4.5 的当前企业身份条件，不能将源对话或其他未发布的个人资源开放给企业。

## 3 素材与文件夹管理

### 3.1 素材查询范围

个人素材包含本人上传文件及已收藏历史文件；企业素材包含成员直接上传文件和个人发布形成的企业副本。

- 按资源归属限定个人或当前企业范围，同一标识只返回一次。
- 查询整个空间时包含根目录及文件夹中的有效文件；查询具体文件夹时只返回其所属文件。
- 根目录表示文件未分配文件夹，不占用文件夹额度。
- 文件夹支持按名称搜索，个人与企业范围分别执行访问校验后返回匹配结果。
- 改变文件查看方式不改变文件归属、查询条件或选择结果。

### 3.2 文件夹管理

个人空间文件夹由本人维护，企业文件夹由企业管理员维护。仅支持一级文件夹；每个个人空间及每个企业分别最多 20 个有效文件夹，根目录不计数。

| 功能 | 操作及结果 | 校验和提示 |
| --- | --- | --- |
| 新建 | 用户确定个人或当前企业范围后输入名称，保存成功创建空文件夹 | 名称必填，去首尾空格，最多 40 字；为空提示“请输入文件夹名称”，重名提示“已有同名文件夹，请更换名称。”；达到上限提示“最多可创建 20 个文件夹。” |
| 重命名 | 带入原名称，用户修改并确认后仅更新名称，文件和目录标识保留 | 与新建使用同样命名校验；名称未变化直接结束，不重复写入；成功提示“文件夹已重命名。” |
| 删除 | 二次确认后删除目录，将全部所属文件移回同一空间根目录，释放目录额度 | 标题“删除文件夹‘{{folderName}}’？”，说明“文件夹内素材将移回根目录，不会删除素材。文件夹删除后不可恢复。”；确认“删除”，取消“取消” |

- 删除包含不同上传人文件的企业文件夹时，管理员将全部所属文件移回企业根目录，文件责任人不变。
- 文件夹删除不进入回收站，文件内容、名称、收藏状态及资源标识不变；查询已删除的当前目录时返回该空间文件集合。
- 原目录中的已删除文件保留在回收站，之后恢复到根目录。
- 成员尝试维护企业文件夹时拒绝执行，提示“仅管理员可维护企业文件夹。”。
- 目录已被其他人删除时，不继续重命名或移动文件到该目录，提示“文件夹已不存在，请刷新后重试。”。
- 新建与删除并发时仍需保证有效文件夹不超过 20 个；删除目录与解除文件归属必须一起完成，失败不返回成功状态。

### 3.3 素材分类与查询

| 项目 | 规则 |
| --- | --- |
| 分类 | 全部、图片、视频、文档、其他，沿用历史文件识别规则 |
| 搜索字段 | 文件名称、说明、标签、关联商品名称 |
| 搜索范围 | 当前个人／企业空间，可进一步限定具体文件夹 |
| 搜索方式 | 不区分大小写的包含匹配；范围、目录、类型、关键词共同约束查询 |
| 排序 | 默认更新时间倒序，允许更新时间正序；缺少更新时间时使用创建时间，同值时按文件标识稳定排序 |
| 时间更新 | 上传、重命名、移动、内容维护更新更新时间；引用单独记录最近使用时间 |
| 分页 | 默认 20 项，支持 10／20／50 项；条件或排序变化后从第一页查询，页码始终位于有效范围 |

### 3.4 文件上传

支持用户选择文件、多文件上传、拖拽文件及粘贴文件。目标空间和文件夹采用发起上传时的有效选择，默认保留原文件名。

| 项目 | 规则 |
| --- | --- |
| 单文件大小 | 不超过 20MB |
| 支持格式 | 图片、视频、音频，以及 PDF、DOCX、XLSX、PPTX、TXT、MD、CSV、JSON、ZIP、SVG |
| 企业上传 | 当前企业成员可上传到企业根目录或任一有效文件夹，记录真实上传人 |
| 多文件处理 | 独立校验格式、大小及读取结果，成功文件保留，失败文件返回原因 |
| 入库结果 | 记录文件标识、格式、大小、内容地址、来源、创建时间和目标目录关系 |

单个文件处理状态为待处理、处理中、成功或失败。失败文件不产生可引用的有效资源。目标失效或权限变化时阻止该文件入库，允许重新指定有效目标后重试。

超过 20MB 提示“文件超过 20MB，请选择更小的文件。”；格式不支持提示“暂不支持该文件格式。”；读取失败提示“文件读取失败，请重新上传。”。成功上传的文件立即加入目标素材集合，不因其他文件失败撤销。

### 3.5 文件维护与批量处理

预览、引用、下载按 2.4.1—2.4.3 执行；素材引用后跳转创作聊天框并加入附件，不自动发送。个人素材发布按 3.7 执行，企业文件不提供再次发布。

#### 3.5.1 重命名

用户修改文件名主体并确认，保留原扩展名。主体必填，去首尾空格，最多 200 字，不允许 `\ / : * ? " < >` 及竖线。允许不同文件使用同一名称，按文件标识区分。

名称为空提示“请输入文件名称。”；包含禁用字符时指出不可用字符。确认成功更新文件名及更新时间，提示“文件已重命名。”；文件内容、文件夹归属及已有商品关联不变。取消或名称未修改时不写入。

#### 3.5.2 移动

用户选择同一空间内的根目录或有效文件夹并确认，将文件归属改为目标目录，更新文件更新时间。不可通过移动改变个人／企业归属。

目标为原位置时不重复写入。成功提示“素材已移动到目标位置。”；目标失效提示“目标文件夹已不存在，请重新选择。”，保留选择供修改。文件标识、内容和责任人保持不变。

#### 3.5.3 删除

需要二次确认，标题“删除该文件？”，说明“删除后在回收站保留 7 天，到期自动销毁。”；若个人文件同时存在于创作历史，补充“该文件也会从创作历史中移除。”。

确认后移入该空间回收站，取消未发送聊天框中的对应引用，提示“已移入回收站，7 天内可恢复。”；取消不改变资源。企业副本删除不影响个人原件，个人原件删除不影响企业副本。保留期内保存责任人、目录、内容和名称供恢复使用，到期按 8.2 销毁。

#### 3.5.4 批量操作

支持批量下载、删除、移动和引用。下载、引用及选择范围沿用 2.5；批量删除说明为“删除所选 {{count}} 个文件？删除后在回收站保留 7 天，到期自动销毁。”。

批量移动一次确定同空间目标目录，确认后统一移动；全部已在目标目录时不执行写入。批量删除和移动要求每个文件都有维护权限，混入他人无权限文件时整批不执行，提示“所选文件中包含无维护权限的素材，请调整选择。”。

### 3.6 文件打开、阅读器与下载

创作历史、素材及创作聊天框中的同一文件共用以下格式规则。归集类型、打开方式、上传准入及 AI 输入支持范围分别判断；本表不自动扩大 3.4 和 6.2 的上传准入格式。

#### 3.6.1 格式与打开方式

| 文件类型 | 打开方式 | 备注与功能规则 | 推荐阅读器／插件 |
| --- | --- | --- | --- |
| txt、log、json、yaml、yml、xml、js、ts、tsx、jsx、py、java、go、css、html、sh、sql 等已识别文本代码 | 侧边栏打开 | 只读；支持语法高亮和格式化；格式化只改变当前阅读内容，不写回文件；HTML 按源码阅读，不执行或渲染为网页 | CodeMirror |
| md、markdown | 侧边栏打开 | 只读；默认渲染文档内容，支持切换查看原文；切换不修改文件 | markdown-it |
| pdf | 侧边栏打开 | PDF 翻页、缩放和文档内搜索 | PDF.js |
| png、jpg、jpeg、webp、gif | 会话中／侧边栏打开 | 图片支持缩放、拖动查看；GIF 支持动画播放 | 浏览器原生图片预览 |
| svg、heic、heif、bmp、tiff | 侧边栏打开 | 转为 PNG 后预览；SVG 转换失败时显示只读源码；转换结果不覆盖原文件 | 图像转换能力；SVG 源码降级使用 CodeMirror |

| xlsx | 侧边栏打开 | 只读；支持切换工作表；公式按解析结果展示已保存计算值，无计算值时展示公式文本，不自行重新计算 | SheetJS CE + 表格组件 |

| pptx | 侧边栏打开 | 先转换为 PDF，再提供 PDF 预览能力，不使用自研幻灯片渲染器 | LibreOffice headless 转 PDF + PDF.js |

| doc、ppt、xls | 打开文件目录 | 不提供内置预览 | 本机默认应用 |
| dmg、pkg、app、exe、未知格式及其他未支持文件 | 打开文件目录 | 不提供内置预览；只定位文件，不自动安装或运行 | 本机默认应用 |

#### 3.6.2 阅读与转换规则

- 文本／代码根据格式应用对应语法高亮；未识别语言但可读的纯文本按原文读取。格式化失败保留原文，提示“格式化失败，已保留原文。”。
- Markdown 渲染及原文使用同一文件内容；渲染不执行脚本。HTML 文件作为代码阅读，不执行文件中的脚本。
- PDF 搜索范围为当前文档可提取的文本；无可搜索文本时提示“该文件暂无可搜索文本。”，仍允许翻页、缩放和下载。
- CSV、TSV 按对应分隔符解析；XLSX 保留工作表名称，默认读取第一个工作表，用户可切换其他表。读取不改变原工作簿及公式。
- 图像转 PNG 和 PPTX 转 PDF 仅生成预览文件；保留原格式、原内容和资源标识，下载时仍下载原件。转换结果不能替代原件参与文件分类。
- 转换开始后提示“正在生成预览，请稍候。”；相同原件内容的重复打开可复用已有转换结果，原文件变化后不得复用旧预览。
- SVG 转 PNG 失败时自动读取 SVG 源码，提示“图片转换失败，已切换为源码查看。”；源码读取也失败时提供原件下载。
- 其他图像转换、PPTX 转 PDF 或文档解析失败时提示“文件预览失败，请下载原文件查看。”，保留原文件，不清除用户其他输入。
- 视频无法由浏览器解码时提示“当前浏览器无法播放该视频，请下载原文件查看。”，允许下载原视频。
- 读取原件、生成转换文件及获取预览结果均使用原资源的访问权限，企业成员无权访问的文件不能通过转换结果访问。

#### 3.6.3 本机文件目录处理

对表中使用“打开文件目录”的格式，只定位文件所在目录，由用户选择本机默认应用打开：

1. 已有可定位的本机文件时，定位该文件及所在目录，不重复下载。
2. 尚无本机文件时，先下载原文件，成功后定位目录；用户取消下载则终止该操作。
3. 宿主客户端具备目录定位能力时调用对应能力；纯 Web 通过浏览器下载记录由用户执行“在文件夹中显示”。浏览器未提供可调用定位能力时，完成下载后提示“文件已下载，请在浏览器下载记录中打开所在文件夹。”。
4. 不自动执行、安装或解压文件。本机应用的打开行为由用户自行发起。
5. 下载失败提示“下载失败，请重试。”；已下载文件被移走或删除时，提示“本机文件不存在，请重新下载。”，允许重新下载。

#### 3.6.4 复制与下载

支持复制的图片，复制成功提示“图片已复制”；失败提示“复制失败，请下载原图。”。

下载始终提供原文件，保留名称及扩展名，不以缩略图、PNG 转换结果、PDF 转换结果或视频封面替代原件。引用是否可被 AI 读取在发送时按目标模型检查，不能以可预览作为可生成的判断依据。

### 3.7 发布至企业空间

个人素材使用与创作历史相同的发布流程，完整规则见 2.4.5：

- 必须是当前企业身份，发布目标只能是该身份对应企业；个人身份无法发布。
- 选择企业根目录或有效文件夹后确认，创建独立企业副本并保留个人原件。
- 同一源文件在同一企业中最多存在一个未删除的发布副本；已有副本时提示已发布，不覆盖内容或更换目录。
- 已有副本已删除时可再次发布；恢复旧副本前检查是否已有有效副本，防止重复恢复。
- 同名文件分别依据源资源标识判断，发布成功、取消、身份失效和目标失效的处理与提示按 2.4.5 执行。

企业副本的上传人／发布人为维护责任人；企业成员可以使用，维护权限按 3.8 执行。

### 3.8 素材与文件夹权限

个人素材及个人文件夹仅本人可维护。企业资源归属及维护权限使用真实企业标识和成员标识判定，姓名仅用于识别。

| 企业操作 | 普通成员 | 管理员 |
| --- | --- | --- |
| 查询、预览、下载、引用文件 | 可使用企业全部有效文件 | 可使用企业全部有效文件 |
| 上传文件 | 可上传至根目录或任一有效文件夹 | 可操作 |
| 新建、重命名、删除文件夹 | 无权限 | 可维护全部企业文件夹 |
| 文件重命名、移动、删除 | 仅本人上传或发布的文件 | 可维护全部企业文件 |
| 恢复文件 | 仅本人上传或发布的文件 | 可恢复全部企业文件 |

企业文件以该副本的上传人或发布人为维护责任人。移动文件不改变责任人。

批量下载、引用可包含不同责任人的文件；批量删除、移动要求全部对象均有维护权限。存在无权限、已删除或归属变化的对象时整批阻止执行，返回具体原因，保留选择供调整。

读取和执行均校验企业成员状态、资源有效性及目录有效性。权限以执行时为准，失败不得产生未说明的部分变更。

## 4 风格管理

### 4.1 业务用途与字段

风格方案保存店铺基调、商品系列风格、活动视觉和满意作品的视觉参考。用户在个人空间创建方案，发布形成企业方案。

| 字段 | 校验规则 |
| --- | --- |
| 方案名称 | 必填，去首尾空格，最多 60 字 |
| 风格描述 | 选填，最多 2000 字，可描述光线、色调、材质、背景和构图 |
| 参考图 | 选填，最多 5 张，JPG／PNG／WebP，单张不超过 5MB；可上传或引用已有有效图片 |

方案仅维护名称、风格描述和参考图。名称必填，风格描述与参考图至少配置一项才可保存。图片按内容引用地址去重，保留用户确认的顺序。

#### 4.1.1 新用户默认风格

新用户首次初始化个人资产空间时，系统自动配置 **1 个默认风格方案**，使用户可以直接查看、引用或在此基础上修改。

- 默认内容取自平台配置的风格模板，包含方案名称，并至少配置参考图或风格描述中的一项，满足方案保存条件。
- 初始化时创建属于该用户的个人方案副本，使用独立方案标识；平台模板的后续更新不覆盖个人副本。
- 默认方案支持查看、引用、编辑、删除，以及企业身份下发布至企业空间，权限与普通个人风格一致。
- 默认方案仅加入个人资产，不自动创建企业副本，也不自动引用到聊天框。
- 每个个人空间仅初始化一次；刷新、再次登录和切换资源范围不重复创建。用户编辑或删除默认方案后，不自动还原或补回；删除后可按回收站规则恢复。
- 默认模板不可用或创建失败时，记录该项未完成并允许重试；重试只处理未完成项，不重复创建已成功配置的方案。

### 4.2 创建、编辑与内容确认

- 编辑以已保存方案为基础，保存成功后统一更新内容及更新时间；取消不改变已保存方案。
- 参考图支持新增、移除和更换，超过上限时拒绝超额内容并说明原因；已确认内容保留。
- 用户可在保存前查看本次方案的名称、风格描述和全部参考图，内容与最终保存数据一致。
- 第一张参考图作为方案代表图；无参考图时采用系统默认标识。
- 从历史或素材图片创建方案时，带入原图片并生成可修改的初始名称；保存风格不改变原文件。
- 企业方案记录独立标识、原方案标识、最初发布人和发布时间，发布人为企业副本的维护责任人。编辑仅更新内容及最新编辑时间，个人原件与企业副本独立维护。重复发布处理按 4.5 执行。

### 4.3 权限与查询

| 范围 | 可执行功能 |
| --- | --- |
| 本人个人方案 | 查看、编辑、引用、发布、删除 |
| 企业本人发布的方案或管理员 | 查看、编辑、引用、删除 |
| 企业其他成员发布的方案 | 查看、引用 |

方案归属和权限使用实际企业、成员标识校验。读取及维护时校验资源有效性和成员状态，权限不足时拒绝编辑、删除或恢复；恢复沿用维护权限。

风格查询限定个人或当前企业空间，排除已删除资源。支持名称、描述的不区分大小写包含搜索；固定按更新时间倒序，同时间按资源标识稳定排序。默认每页 20 项，支持 10／20／50 项，查询条件变化后从第一页查询。

### 4.4 引用规则

引用仅包含方案名称、风格描述及全部参考图，一次创作最多一个方案；新选择替换原方案。

点击“引用”后跳转创作聊天框，带入该方案作为风格引用，不自动发送；已有风格时直接替换，已有文字、附件和模特保留。点击移除风格只取消聊天框中的使用，不删除方案。

### 4.5 保存、发布与删除的处理结果

| 操作 | 明确规则及提示 |
| --- | --- |
| 创建／保存 | 名称为空提示“请输入方案名称。”；只有名称无任何内容时提示“请填写风格描述或添加参考图。”；成功提示“风格方案已保存。”；编辑成功提示“风格方案已更新。”；失败保留填写内容，提示“保存失败，请重试。” |
| 发布 | 仅当前企业身份可发布本人个人方案，直接发布到当前企业风格库；同源方案在同一企业已有未删除副本时不重复创建、不覆盖，提示“该风格已发布至企业空间。”；副本已删除可重新发布，原件保留 |
| 删除 | 二次确认标题“删除该风格方案？”，说明“删除后在回收站保留 7 天，到期自动销毁，不会删除方案引用的原素材。”；确认后方案进入对应空间回收站，并移除未发送聊天框中的该风格引用；成功提示“已移入回收站，7 天内可恢复。” |
| 取消／失败 | 取消不改变保存数据；删除失败提示“删除失败，请重试。”，保留原方案 |

参考图超过上限提示“参考图最多 5 张”。图片格式或大小不符合要求时说明支持格式与限制，不清除其他已填写内容。

风格发布的身份判断、同一次确认防重复、企业副本删除后的再次发布及恢复冲突处理，沿用 2.4.5 的规则，判断对象由文件替换为风格方案。

## 5 模特管理

### 5.1 来源与可执行功能

| 来源 | 入库方式 | 本人可执行功能 | 企业使用规则 |
| --- | --- | --- | --- |
| AI 定制 | 根据人物参数生成后保存 | 查看、改名、下载、引用、发布、删除 | 发布后形成企业副本 |
| 用户上传 | 上传人物照片并确认使用权限后保存 | 查看、改名、下载、引用、发布、删除 | 发布后形成企业副本 |
| 官方收藏 | 收藏平台可用模特，或在引用时建立收藏记录 | 查看、下载、引用、移除收藏 | 禁止发布，企业查询及企业引用结果排除官方来源 |

官方名称、图像和人物档案由平台维护，用户收藏保持官方来源。移除只解除本人收藏关系，不删除平台源数据，可再次收藏。

企业自建模特由发布人及管理员维护，其他成员可查看、下载和引用。名称修改仅更新名称及更新时间，保留人物图像、属性、参考图和调整记录。

#### 5.1.1 新用户默认官方模特

新用户首次初始化个人资产空间时，系统自动为其收藏 **1 个官方模特**，使用户可以直接查看、下载和引用。

- 默认对象使用平台配置且处于可用状态的官方模特，建立该用户与官方模特的收藏关系，来源保留为官方。
- 默认收藏与用户主动收藏使用同一规则：同一用户对同一官方模特最多一份有效收藏，不复制为自建模特。
- 默认官方模特不支持修改名称、人物图或属性；用户可以移除收藏，之后可从平台模特库重新收藏。
- 该模特仅存在于个人资产，不进入企业共享，不支持发布至企业空间，也不自动引用到聊天框。
- 每个个人空间仅初始化一次；刷新、再次登录和切换资源范围不重复收藏。用户移除默认收藏后不自动补回，平台后续变更默认对象也不替换已完成初始化的用户收藏。
- 默认官方模特不可用或收藏失败时，记录该项未完成并允许重试；重试不重复创建已成功建立的收藏。

风格方案与官方模特分别记录初始化完成状态，某项失败只重试该项。

### 5.2 平台模特供给

平台模特包含稳定标识、名称、主图、可选三视图、性别、年龄段、人物背景、人设、体型、人物描述、可用状态及更新时间。

- 平台仅返回可用模特；同一用户对同一平台模特只保留一份有效收藏。
- 重复收藏不新增个人记录，提示“已收藏”；引用已收藏对象时复用原收藏关系。
- 平台下架后停止新增收藏及新创作引用；用户原有收藏保留名称和来源，但不能再将其带入创作，提示“该官方模特已下架，请选择其他模特。”。
- 企业资源查询、发布和引用仅接受用户自建来源，官方来源不具备企业归属。

### 5.3 AI 定制参数

| 字段 | 规则及预设 |
| --- | --- |
| 模特名称 | 必填，去首尾空格，最多 60 字，用于资源识别 |
| 性别 | 必填，女／男，支持自定义 |
| 人物背景 | 选填，中国／东亚／东南亚／南亚／中亚／中东／欧洲／拉丁美洲／非洲，支持自定义；默认不选，placeholder：请选择或自定义人物背景 |
| 年龄段 | 必填，青少年／青年／中年／老年，支持具体年龄等自定义值 |
| 体型 | 必填，纤细／标准／微胖／大码，支持自定义 |
| 补充特征 | 选填，最多 1000 字，可补充人设、肤色、发型、妆容、表情、服装、姿态等要求。placeholder：例如：上班族、运动达人等人设；也可补充肤色、发型、妆容、服装和姿态等要求。 |
| 参考图 | 选填，最多 1 张，JPG／PNG／WebP，不超过 3MB，可更换和移除 |

人物属性自定义值最多 60 字，保存去除首尾空格后的有效值。默认性别女、人物背景不选、年龄青年、体型标准。人设通过补充特征填写，随该字段原文传入生成提示词，不单独设置参数或默认人设。所有销售市场提供完整人物背景预设，不按市场绑定或限制，不为地域预设固定肤色、五官或发型。名称只作为资源元数据，不要求出现在生成图中。

人物属性支持选择预设或在该属性的自定义输入中填写，主字段仅显示当前值。选择预设替换已有自定义值；填写自定义内容后使用该内容作为有效值，按 Enter 完成输入。必填属性清空后不能生成，人物背景清空后按未指定处理。

### 5.4 生成流程与状态规则

| 操作 | 输入依据 | 成功结果 |
| --- | --- | --- |
| 首次生成 | 当前有效人物参数、补充特征及可选参考图 | 一张人物主图，保存生成人物时使用的参数 |
| 重新生成 | 最新确认的人物参数、补充特征及参考图 | 新主图替换当前结果，重置上一版调整记录及三视图 |
| 调整人物 | 当前主图与用户本次补充提示词 | 原图作为图像输入、补充提示词原文作为文本输入，得到新主图，原三视图失效 |
| 生成三视图 | 当前成功主图与固定三视图 Prompt | 正面、侧面、背面组合图，与当前主图关联 |
| 再次生成三视图 | 同一当前主图与固定三视图 Prompt | 替换三视图，人物主图保持不变 |
| 保存 | 当前最新成功主图、生成人物时使用的参数、可选三视图及参考图 | 创建一份可复用模特资源 |

- 每次人物生成只产生一张结果；存在成功主图后即可保存，三视图为可选内容。
- 调整人物的补充提示词必填，最多 1000 字；取消调整不改变现有结果。调整仅提交本次用户提示词与当前主图，人物参数与用户补充描述保留在模特资源中，不拼入本次提示词。
- 生成中保留上一成功结果，禁止同一流程重复生成及保存；结果与其生成参数对应保存。
- 生成失败保留上一成功结果与本次输入，允许重试；不能以失败或未交付结果替换成功记录。
- 修改主图后必须使其旧三视图失效；三视图需保持同一人物、发型、体型、服装、比例和光照一致。
- 关闭未保存的创建流程不创建正式模特记录。

### 5.5 模特生成 Prompt

#### 5.5.1 表单变量

| 表单内容 | 变量 | 用途 |
| --- | --- | --- |
| 模特名称 | `{{name}}` | 保存资源名称，不加入生成提示词 |
| 性别 | `{{gender}}` | 直接采用用户确认的预设或自定义值 |
| 人物背景 | `{{appearance}}` | 采用用户确认的预设或自定义值；为空时省略对应行 |
| 年龄段 | `{{age}}` | 直接采用用户确认的年龄段或自定义年龄 |
| 体型 | `{{bodyType}}` | 直接采用用户确认的体型 |
| 补充特征 | `{{features}}` | 采用用户填写的补充描述；为空时省略对应行 |
| 参考图 | `{{referenceImage}}` | 存在时作为独立图像输入，不将图片地址拼入文本 |

变量使用通过字段校验的原始值。自定义值与预设值采用相同传参规则。

#### 5.5.2 首次生成与重新生成

首次生成与按表单重新生成使用同一模板，输出数量固定为 1。

```text
生成一张可用于商品图片和视频创作的人物模特图。
性别：{{gender}}
人物背景：{{appearance}}
年龄段：{{age}}
体型：{{bodyType}}
补充特征：{{features}}

人物正面自然站立，全身完整入镜，人物特征清晰，背景简洁，光线均匀自然。
服装简洁；补充特征明确指定的人设、服装、发型、妆容、表情和姿态按用户要求执行。
只生成同一位人物，不添加文字、姓名、水印或额外人物。
```

参考图存在时，将该图作为图像输入，并追加固定指令：

```text
参考所提供图片中的人物形象，结合以上用户参数生成。
```

参考图为空时省略该指令；人物背景为空时省略“人物背景”行；补充特征为空时省略“补充特征”行。

#### 5.5.3 根据结果调整人物

| 输入 | 规则 |
| --- | --- |
| 图像 | 当前成功主图作为原图 |
| 文本 | 用户本次补充提示词原文 `{{adjustment}}` |
| 输出数量 | 1 |

```text
{{adjustment}}
```

该文本直接作为 AI 编辑指令，不拼接人物参数、模板前后缀或历史调整内容。成功后新图成为下一次调整的原图，模特保存时保留最终人物图、生成人物时的参数及用户补充描述。

#### 5.5.4 固定三视图 Prompt

输入仅使用当前成功主图、以下固定提示词及图像输出配置，生成一张三视图组合图：

```text
请基于提供的人物原图，生成同一人物的全身三视图组合图，包含正面、侧面和背面。
三个视图按正面、侧面、背面的顺序排列，人物等比例、等高度，完整展示头部至脚部。
严格保持原图人物的身份、面部特征、发型、体型、肤色、服装及配饰一致。
人物自然站立，背景统一简洁，光线和色调保持一致；侧面为标准侧身视角，背面为标准背身视角。
仅输出一张三视图组合图，不添加文字、标签、水印或其他人物。
```

首次及再次生成三视图使用同一固定 Prompt，不拼接用户表单值和历史调整提示词。

### 5.6 上传、改名、查询与使用

- 上传模特接受单张 JPG／PNG／WebP，最多 3MB；名称选填，未填写时使用“上传模特”；保存前必须确认照片及人物形象使用权限。
- 自建模特支持快捷改名，Enter 或失焦提交，Esc 取消。提交值去首尾空格；Enter 提交空值返回错误，空值失焦恢复原名称。
- 官方收藏及无维护权限的企业模特禁止改名。
- 模特详情提供名称、主图及存在的三视图供确认；允许选择主图或三视图后下载、引用，操作对象必须与当前确认的图像一致。
- 个人／企业分别查询，搜索模特名称，不区分大小写；固定更新时间倒序，同时间按资源标识稳定排序。
- 默认每页 20 项，支持 10／20／50 项；查询条件变化回第一页，资源总数仅统计有效模特记录。
- 平台模特支持名称搜索与相同分页规则，收藏不改变平台目录。

### 5.7 模特权限

| 对象 | 权限 |
| --- | --- |
| 个人 AI 定制、上传模特 | 仅本人维护，可发布至当前企业 |
| 个人官方收藏 | 本人可使用或移除收藏，不可编辑、发布 |
| 企业自建模特 | 全员可查询、下载、引用；发布人及管理员可改名、删除和恢复 |
| 平台模特源数据 | 平台维护，普通用户不能修改或删除 |

企业发布创建独立模特副本，记录源资源、发布人及发布时间，个人原件保留；两份资源独立维护；重复发布规则按 5.8 执行。

读取、改名、删除、恢复及发布时校验真实成员身份和资源状态。企业责任人使用发布人标识判定，官方来源发布请求必须拒绝。

### 5.8 模特操作的具体行为

| 操作 | 具体行为 |
| --- | --- |
| 收藏官方模特 | 收藏到“我的模特”；成功提示“已收藏至我的模特”；重复收藏不创建记录，提示“已收藏”；引用未收藏官方模特时先建立一份收藏，再将其带入创作聊天框 |
| 引用模特 | 跳转创作聊天框加入模特引用，不自动发送；已有模特时替换，其他文字、附件和风格保留；常规引用带入主图及已有三视图，针对单图引用只带入所选图 |
| 名称修改 | 只修改自建模特名称及更新时间，图片和人物属性不变；空值不能保存，提示“请输入模特名称”；成功提示“模特名称已更新。”；取消恢复原名称 |
| 保存生成／上传模特 | 创建个人模特资源，提示“模特已保存。”；失败保留成功图与填写内容，提示“保存失败，请重试。”；未保存退出不入库 |
| 发布至企业 | 当前企业身份可发布本人 AI 定制或上传模特；官方来源无发布功能，执行请求时拒绝并提示“官方模特不支持发布至企业空间。”；同源模特在同企业已有有效副本不重复创建、不覆盖，提示“该模特已发布至企业空间。” |
| 删除自建模特 | 二次确认标题“删除该模特？”，说明“删除后在回收站保留 7 天，到期自动销毁。”；确认后移入对应空间回收站，取消未发送聊天框中的该模特引用，个人原件与企业副本相互独立 |
| 移除官方收藏 | 二次确认标题“移除该官方模特？”，说明“仅从我的模特中移除，之后可重新收藏。”；确认后解除收藏，取消未发送聊天框中的该引用，不进回收站、不删除平台数据 |

模特发布仅针对当前企业；同一次确认不重复创建，已删除企业副本允许重新发布，恢复旧副本时排除同源有效副本，沿用 2.4.5。取消删除或移除时保持原数据；失败说明原因并保留资源。

缺少必填参数时指出具体字段；人物生成失败提示“模特生成失败，请重试。”，三视图失败提示“三视图生成失败，请重试。”，保留上一张成功图。上传模特未确认使用权限时提示“请确认已获得照片与人物形象的使用权限。”。

## 6 创作资产引用

### 6.1 可引用范围与选择规则

创作过程支持通过资产库及 `@` 查找资源，也支持从资源管理直接发起引用。从素材管理点击引用会跳转创作工作台，资产库内选择则直接加入当前聊天输入框；两种方式共用同一组待发送引用。

| 资源类型 | 可引用范围 | 查询条件 |
| --- | --- | --- |
| 创作历史 | 本人有效历史文件 | 文件类型、名称、标签 |
| 素材 | 本人素材或当前企业有效共享文件 | 空间、文件夹、文件类型、名称、标签 |
| 风格 | 本人方案或当前企业有效共享方案 | 空间、名称、描述 |
| 模特 | 本人自建及官方收藏、企业自建模特 | 空间、名称、保存的人物描述 |

搜索采用不区分大小写的包含匹配。切换资源类型保留本次创作引用，重置该次搜索与文件类型条件；改变空间按新范围查询，不影响已具备访问权限的引用。

素材可查询全部文件夹、未分组文件或某一有效文件夹；文件夹候选仅属于所选个人或当前企业空间，排除已删除目录。全部文件夹包含根目录及所有一级目录，未分组仅返回无有效文件夹归属的文件。文件夹、文件类型及关键词条件共同生效；切换空间后重置文件夹为全部，切换资源类型不沿用其他类型的文件夹限制。

在聊天框资产库中点击资源，直接加入当前输入内容，选择器保持打开，便于连续添加；点击选择器外部或按 Esc 关闭，已选择内容保留。移除只取消本次使用，不删除原资源。重复选择同一文件不重复添加。

空间与文件夹筛选属于当前选择流程，展开或选择筛选项不得关闭资产选择器。引用模特时通过人物图及名称确认选择对象，不以人物描述替代名称。

### 6.2 引用数量与文件上传

| 对象 | 限制 |
| --- | --- |
| 普通文件与直接上传附件 | 合并去重后最多 20 个，重复标识计一次 |
| 风格 | 最多 1 个，新选择替换原方案 |
| 模特 | 最多 1 个，新选择替换原模特 |
| 方案内参考图、人物三视图 | 随对应资源带入，遵守资源内部数量限制，并纳入生成工具的实际输入校验 |

直接上传附件支持图片、视频及 PDF／TXT／DOCX／XLSX／CSV，单文件最多 20MB；各文件独立校验和读取，失败文件不加入有效引用。

20 个文件上限同时约束直接上传、资源管理批量引用及资产库选择。超过上限拒绝新增超额内容，保留已有引用；目标工具上限更低时，发送前返回具体限制并要求减少输入。

### 6.3 引用内容确认

| 引用对象 | 用户可确认的内容 | 移除结果 |
| --- | --- | --- |
| 普通文件 | 名称、类型、可用内容；支持格式可预览 | 取消该文件本次创作使用 |
| 风格 | 方案名称、风格描述及参考图 | 取消整份方案本次创作使用 |
| 模特 | 名称、选定人物图或主图与三视图集合 | 取消该模特本次创作使用 |

通过模特管理的一般引用带入主图及已有三视图；针对某张图的引用只带入所选图像。风格引用整体带入描述及参考图。

### 6.4 商品库与知识库关系

资产查找覆盖素材库四类资源。商品／SKU 引用使用独立能力，统一输入结构预留知识来源。

商品／SKU 确定商品外观、规格与事实；文件提供任务输入及参考；风格提供视觉约束；模特提供人物参考。知识接入需返回可访问文档、相关片段及来源，引用前校验解析状态和权限。

### 6.5 引用权限

候选资源和执行资源均按本人或当前企业的授权范围获取；企业范围过滤官方模特。选择后至发送前如发生资源删除、成员退出或权限变化，应阻止失效资源进入执行输入，返回具体资源及原因。

引用权限不包含维护权限，成员可引用他人有效共享资源，不能因此修改其内容。

### 6.6 发送前检查与结果

| 检查项 | 不通过时的行为和提示 |
| --- | --- |
| 创作要求 | 文字为空时不发送，提示“请输入创作要求。” |
| 附件读取 | 存在读取中的文件时不发送，提示“附件正在读取，请稍后发送。”；读取失败项需移除或重新上传 |
| 普通文件数量 | 合计超过 20 个时不发送，提示“最多引用 20 个文件，请减少附件。” |
| 资源可用性 | 已删除、未收藏历史文件已到期、企业权限失效时，指出资源并提示“素材已失效或无访问权限，请移除后重试。” |
| 模型格式及数量 | 格式不支持时提示“当前模型不支持文件‘{{fileName}}’的 {{fileType}} 格式，请移除或更换文件。”；超过模型输入数量时提示“当前模型最多支持 {{limit}} 个输入文件，请减少附件。”；保留文字和引用 |

发送成功后清空本次文字及待发送引用；发送失败保留原文字和引用，提示“发送失败，请重试。”。

## 7 创作生成 Prompt

用户发送创作要求时，将聊天框中的文字、附件、风格及模特传入生成服务。发送前按 6.6 检查具体附件和输入限制。

### 7.1 通用结构

```text
{{userPrompt}}
{{taskParameterPrompt}}
{{stylePrompt}}
{{modelPrompt}}
```

用户任务、任务参数、风格指令、模特指令按顺序组合；不存在的部分省略。任务参数按“参数名称：用户确认值”逐行生成，不重复写入同一要求。

商品／SKU 资料作为商品事实输入，图片、视频及文档按目标工具的输入能力解析。文档内容作为参考资料处理；视觉风格不改写商品外观、规格等事实。

### 7.2 引用风格 Prompt

| 变量 | 来源 |
| --- | --- |
| `{{styleName}}` | 风格方案名称 |
| `{{styleDescription}}` | 已保存的风格描述 |
| 风格图像输入 | 方案全部参考图，标记用途为视觉风格参考 |

`{{stylePrompt}}` 使用以下模板：

```text
本次创作采用风格方案“{{styleName}}”。
风格要求：{{styleDescription}}
参考随附风格图片中的色调、光线、材质与构图，不将其中的其他商品或人物直接作为本次创作主体。
保持本次创作商品的真实外观、规格及该方案的视觉基调。
```

描述为空时省略“风格要求”行；参考图为空时省略参考图片指令。方案名称用于识别，不作为画面文字生成。

### 7.3 引用模特 Prompt

`{{modelPrompt}}` 使用以下模板：

```text
本次创作人物采用所引用的模特“{{modelName}}”，以随附模特图片为人物参考，保持人物形象一致。
```

`{{modelName}}` 来自所选模特名称；图像输入使用本次创作选定的主图、三视图或二者集合。模特名称仅用于识别，不要求写入画面；本段不重复拼接原人物生成参数或调整历史。

## 8 回收站与异常处理

### 8.1 状态变更

| 动作 | 数据结果 | 后续规则 |
| --- | --- | --- |
| 删除文件、风格、自建模特 | 标记删除并记录时间 | 资源不再参与正常查询和新任务引用，按权限可恢复 |
| 删除文件夹 | 删除目录并解除文件归属 | 文件保留在同空间根目录，目录不进入回收站 |
| 移除官方收藏 | 解除本人收藏关系 | 平台源不变，可再次收藏 |
| 恢复文件 | 清除删除状态，恢复原空间及有效目录关系 | 原目录失效时恢复至根目录，历史文件继续按原有效期判断 |
| 恢复风格或自建模特 | 清除删除状态，恢复原归属 | 后续维护及引用重新按当前权限校验 |

个人资源仅本人可恢复；企业成员仅可恢复本人上传或发布的资源，管理员可恢复全部企业资源。恢复时复核成员状态和资源归属。

点击恢复后清除删除状态，返回原空间；原文件夹不存在则回根目录。成功提示“已恢复”；失败提示“恢复失败，请重试。”。恢复历史文件不重置创建时间，已超过 365 天且未收藏时提示“文件已超过创作历史保留期限，无法恢复。”；已收藏文件仍可恢复到个人素材。

恢复已发布企业副本前，按源资源和企业标识检查同源有效副本；已存在时不重复恢复，提示“企业空间已有该资源，无需重复恢复。”。恢复前同时执行 8.2 的期限校验。

### 8.2 保留期限与到期销毁

| 项目 | 规则 |
| --- | --- |
| 适用对象 | 个人及企业回收站中的文件、风格方案、自建模特；文件夹和官方收藏移除不进入回收站 |
| 保留期限 | 从成功删除时间起连续保留 7 × 24 小时，精确到时间点；不按自然日或零点计算 |
| 有效期判断 | 当前时间早于删除时间加 7 天时可恢复；等于或超过到期时间立即失效，不返回回收站列表和可恢复数量 |
| 剩余天数 | 剩余时间不少于 24 小时，向上取整为整数天，展示“7天”“2天”“1天”等；大于 0 且不足 24 小时展示“<1天”，文字标红；不展示小时和分钟 |
| 时间更新 | 剩余时间随实际时间更新；再次访问、恢复页面及执行恢复时重新校验，不延长保留期限 |
| 到期销毁 | 自动销毁该回收站资源记录及其独立持有的文件内容，移除失效引用与关联；不要求用户确认，无法恢复；共享底层文件仍被其他有效资源使用时不得一并删除 |
| 恢复后的计时 | 成功恢复后取消本次回收站计时；以后再次删除，从新的删除成功时间重新计算 7 天；恢复不延长创作历史本身的保留期限 |
| 重复删除 | 已在回收站的资源不重复创建记录、不重置删除时间 |
| 销毁边界 | 企业副本与个人原件独立计算；销毁一个不影响另一个。风格销毁不删除其引用的原素材，模特销毁不删除独立保存的参考原图 |
| 手动销毁 | 不提供永久删除或清空回收站功能 |

用户发起删除时，二次确认需明确“将在回收站保留 7 天，到期自动销毁”。删除成功提示“已移入回收站，7 天内可恢复。”。

恢复请求在资源已到期或已销毁时拒绝执行，提示“资源已到期销毁，无法恢复。”，同步移除失效记录并更新数量。到期销毁与恢复同时发生时只允许一个结果成功，不得恢复已销毁资源。清理重复执行不重复扣减或影响有效资源。

### 8.3 异常处理

| 异常 | 处理规则 |
| --- | --- |
| 查询无结果 | 区分尚无资源与查询不匹配；允许新建、上传或重新查询 |
| 文件夹额度不足 | 拒绝新建并说明上限，已有目录不受影响 |
| 格式、大小或文件读取失败 | 该文件不入库或不引用，返回原因，其余成功项保留 |
| 文件不做内置预览 | 按格式定位本机文件目录；无目录定位能力时完成原件下载并提供浏览器下载记录操作说明 |
| 解析／转换失败 | SVG 转换失败退回源码；其他失败保留有效原件下载，提示具体原因 |
| 发布或移动目标失效 | 不写入无效归属，允许改用有效目录或根目录 |
| 权限不足或成员身份变化 | 拒绝对应动作，重新校验可用资源与待提交引用 |
| 保存失败 | 提示“保存失败，请重试。”，保留填写内容及已上传成功的文件，原资源不被未成功保存的数据覆盖 |
| 重复提交 | 使用请求标识保证同一操作幂等，避免重复资源 |
| 并发修改或删除 | 检查资源版本及有效状态，冲突时返回原因，避免覆盖未确认内容 |

## 9 验收规则

| 编号 | 功能 | 验收标准 |
| --- | --- | --- |
| H01 | 历史归集与分类 | 只归集有效交付文件；全部为四类并集，标识不重复 |
| H02 | 历史查询 | 固定创建时间倒序，关键词、分类及分页共同生效，页码边界正确 |
| H03 | 收藏与发布 | 收藏后历史保留；当前企业身份才能发布；同源同企业不重复发布、不覆盖，原件保留 |
| H04 | 历史批量处理 | 支持下载、删除、收藏、引用，退出与条件变更清空选择 |
| F01 | 文件夹额度 | 每空间最多 20 个一级文件夹，同空间名称校验有效 |
| F02 | 删除文件夹 | 文件回根目录，目录不进回收站，文件关系和权限保留 |
| F03 | 企业权限 | 成员仅维护本人资源，管理员维护全部企业资源；目录维护仅管理员 |
| F04 | 文件维护 | 上传独立反馈，重命名保留扩展名，移动仅限同空间有效目录 |
| F05 | 格式分类与预览 | JSON、日志、代码等归入文档；按格式表打开只读阅读器，HTML 阅读源码；格式化不修改原件 |
| F06 | 文档与表格 | MD 渲染／原文切换，PDF 搜索翻页缩放，CSV／TSV 只读表格，XLSX 多工作表及公式结果展示正确 |
| F07 | 转换与播放 | 特殊图片转 PNG，SVG 失败回退源码，PPTX 转 PDF；GIF 播放，MP4／MOV 新窗口播放器 |
| F08 | 本机目录与下载 | 不支持内置预览的格式定位目录；Web 说明下载记录定位方式；下载保留原件，不自动运行文件 |
| S00 | 默认风格初始化 | 首次个人空间初始化仅创建 1 个个人方案副本，可编辑引用；重复进入不新增，删除后不自动补回 |
| S01 | 风格校验 | 名称必填，风格描述或参考图至少一项有效；参考图最多 5 张 |
| S02 | 风格数据 | 名称、风格描述和参考图顺序与保存数据一致，编辑取消不改原方案 |
| S03 | 风格复用 | 点击引用跳转聊天框，同类风格替换，仅带入方案名称、风格描述及参考图 |
| M00 | 默认模特初始化 | 首次个人空间初始化仅建立 1 个官方收藏，保持官方限制；不进入企业，移除后不自动补回 |
| M01 | 人物生成 | 表单值准确代入双花括号变量，单张结果与参数对应，失败保留上一成功结果 |
| M02 | 人物调整与三视图 | 调整只提交原图与补充词原文；三视图使用固定 Prompt；重生主图使旧三视图失效 |
| M03 | 官方收藏 | 收藏幂等，不允许改名及企业发布，移除不影响平台源 |
| M04 | 企业模特 | 只返回自建来源，责任人与管理员可维护，其他成员可使用 |
| M05 | 模特查询 | 名称搜索、更新时间排序及分页正确，资源数量仅统计有效记录 |
| M06 | 定制参数 | 人物背景选填且默认空，人设通过补充特征传入；属性支持预设及独立自定义输入，无额外默认人设 |
| R01 | 引用集合 | 连续选择即时加入，文件去重，切换查找条件不丢失有效引用 |
| R02 | 引用限制 | 文件合计最多 20 个，风格和模特各 1 个，超限不破坏已有引用 |
| R03 | 创作引用与发送 | 引用加入聊天框不自动发送；发送前明确检查输入；失败保留，发送成功清空待发送内容 |
| R04 | 生成输入 | 按模板生成风格及模特指令；变量、附件和配置对应，失效或不支持的输入明确报错 |
| R05 | 选择器查询与关闭 | 个人／企业切换及文件夹筛选不误关；文件夹、类型与关键词共同过滤，切换空间重置文件夹；点击外部关闭且保留已引用内容 |
| D01 | 删除恢复 | 按对象类型和权限处理，原目录失效时恢复根目录 |
| D02 | 回收站时效 | 删除满 7 × 24 小时自动失效并销毁；期限内支持恢复，再次删除重新计时，重复删除不延期 |
| D03 | 剩余时间 | 仅展示整数天或“<1天”，不足 24 小时标红，到期不显示“0天”且不可恢复 |
| D04 | 销毁范围 | 个人与企业副本独立；不销毁其他有效资源持有的内容；到期资源重进应用不回流，清理幂等 |
