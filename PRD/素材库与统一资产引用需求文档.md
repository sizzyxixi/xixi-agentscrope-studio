# 素材库与统一资产引用需求文档

## 1 功能范围

本需求覆盖店铺商品内容生产中的历史文件复用、个人及企业素材管理、风格管理、模特管理及创作聊天框中的资产引用。

| 模块 | 适用范围 | 主要场景 |
| --- | --- | --- |
| **资源归属** | 个人资产／企业资产 | 区分本人私有资源与当前企业共享资源，按归属确定访问及维护权限 |
| **创作历史** | 本人已交付的生成及编辑结果 | 找回历史作品，继续修改、收藏或发布 |
| **素材** | 个人与企业文件及一级文件夹 | 维护常用背景、参考图、视频及文件 |
| **风格** | 个人与企业风格方案 | 复用店铺基调、系列风格或活动视觉 |
| **模特** | 个人自建及官方收藏、企业自建模特 | 商品上身、人物出镜及使用场景制作 |
| **创作资产引用** | 本人及企业可访问资源 | 将文件、风格或模特带入创作聊天框，并作为 AI 输入 |
| **回收站** | 删除后 7 天内可按权限恢复的资源 | 恢复误删文件、风格和自建模特，到期自动销毁 |

## 2 创作历史

### 2.1 概要

创作历史即用户在会话过程中所产生的所有AI产物。为已上线功能。

本期调整：

- 增加文件分类
- 文件类型支持在线预览，以当前已实现能力为主
- 增加收藏至素材、发布至企业空间、以及删除做回收站处理
- 调整批量操作的交互规则
- 移除排序方式的切换

### 2.2 文件分类

| 分类 | 判断范围 |
| --- | --- |
| **全部** | 当前查询范围内图片、视频、文档、其他四类有效文件的并集 |
| **图片** | PNG、JPG／JPEG、WebP、GIF、SVG、HEIC／HEIF、BMP、TIFF，以及 PSD、RAW、CR2 等图像源文件 |
| **视频** | MP4、MOV 及已识别的视频媒体类型 |
| **文档** | 具体格式见下表 |
| **其他** | 音频、ZIP 等压缩文件、DMG／PKG／APP／EXE 等安装或应用文件、未知格式及其余文件 |

归入“文档”的格式：

| 文档类型 | 扩展名 |
| --- | --- |
| **文本、日志与结构化数据** | txt、log、json、yaml、yml、xml |
| **代码及脚本** | js、ts、tsx、jsx、py、java、go、css、html、sh、sql 等已识别的文本代码格式 |
| **Markdown** | md、markdown |
| **PDF** | pdf |
| **分隔值表格** | csv、tsv |
| **Office** | xlsx、docx、pptx、doc、ppt、xls |
| **其他已识别文档** | rtf、odt、ods、odp 等 |

### 2.3 单文件操作

#### 2.3.1 文件打开与预览

用户点击文件名称或缩略内容后，主要有如下场景：

1. 图片：放大预览（维持当前逻辑）
2. 视频：新窗口打开浏览器原生播放器
3. 文档：以“文件管理”需求中所实现的效果为准，通过侧边栏只读阅读器打开
4. 其他：提示 “不支持在线预览，请直接下载文件。”

#### 2.4.2 引用

**【已有能力】**

1. 用户点击“引用”，跳转至店铺经营工作台的聊天输入框，将该文件作为附件加入。
2. 聊天框已有文字及其他引用保持不变，不自动发送消息。用户继续输入创作要求后自行发送。
3. 同一文件已在聊天框中时，不重复添加，提示“该素材已引用”。
4. 普通文件附件去重后最多 20 个；已满 20 个时，不新增文件，提示“最多引用 20 个文件，请先移除部分附件。”。
5. 文件已删除、历史文件已到期且未收藏，或用户已无访问权限时，不带入文件，提示“该文件已失效或无访问权限，请重新选择。”。
6. 不支持在线预览的文件仍可作为附件加入。能否读取该格式，已模型能力为准。

#### 2.4.3 下载

**【已有能力】**

点击“下载”后下载原文件，文件名采用当前保存的名称，扩展名与原文件格式一致；图片不下载缩略图，视频不下载封面。

#### 2.4.4 收藏至素材

1. 点击“收藏至素材”，将文件加入“素材”，支持选择移动到具体的文件目录下，默认根目录。个人素材永久保存该文件。
2. 创作历史中的原文件继续保留，原创建时间及 365 天有效期不变。
3. 收藏使用同一文件标识，历史与个人素材共用文件内容、名称、标签及删除状态。
4. 成功提示“已收藏至素材”；重复收藏不生成新文件，提示“已收藏至素材”。
5. 收藏后用户可在素材中移动文件夹或重命名；这些修改同步作用于同一历史文件。

#### 2.4.5 发布至企业空间

用户当前使用的身份必须为企业身份，且是该企业的有效成员。仅账号加入过企业、但当前使用个人身份，不满足发布条件；个人身份不提供发布操作。

1. 用户发起发布后选择当前企业的根目录或一个有效文件夹；默认根目录。
2. 确认后创建企业文件副本，个人原件保留；企业副本记录发布人，所有有效企业成员均可查看、引用和维护。
3. 成功提示“已发布至企业空间”；取消或关闭本次发布不创建文件。
4. 同一源文件允许重复发布、不覆盖、不改变已有副本的目录。
5. 已有企业副本已移入回收站时，允许再次发布，创建新副本，原回收站记录保留；如恢复旧副本，允许恢复。
6. 原件重命名、移动、收藏及删除不改变已发布副本；个人原件修改后重复发布也不覆盖企业内容。
7. 目标文件夹失效时保留发布选择，提示“目标文件夹已不存在，请重新选择。”
8. 重名处理，不阻断流程。在当前文件名后面自动补充唯一序列号，规则由开发定义即可

#### 2.4.6 删除

点击“删除”必须二次确认，确认前不修改文件状态。

| 项目 | 文案或行为 |
| --- | --- |
| **确认标题** | 删除该文件？ |
| **未收藏至素材的文件做删除** | 删除后在回收站保留 7 天，到期自动销毁。 |
| **已收藏至素材的文件做删除** | 该文件将从创作历史和我的素材中同时移除，在回收站保留 7 天，到期自动销毁。 |
| **确认操作** | 删除 |
| **取消操作** | 取消；关闭确认也视为取消 |

确认删除后：

- 将该文件标记为已删除并记录删除时间，移入个人回收站，不立即销毁原文件。
- 创作历史、个人素材和可引用资源中不再返回该文件；若尚未发送的聊天输入框已引用该文件，同步移除该引用。
- 保留原文件内容、名称、目录关系和收藏状态，供恢复使用；
- 该文件已发布的企业副本保留，不受个人删除影响。
- 成功提示“已移入回收站，7 天内可恢复。”；失败提示“删除失败，请重试。”，不清除未成功删除的资源。

### 2.5 批量操作

批量选择只针对当前查询页，支持逐项选择、取消、全选当前页及同页连续范围选择。没有选中文件时，不能执行批量动作。

| 功能 | 具体处理 |
| --- | --- |
| **批量下载** | 只选一个时下载原文件；选择多个时打包下载。任一原件读取失败时不生成不完整压缩包，说明失败文件，保留选择供重试 |
| **批量删除** | 二次确认标题“删除所选 {{count}} 个文件？”，说明“删除后在回收站保留 7 天，到期自动销毁。已收藏文件也会从我的素材中移除。”；确认后全部移入回收站，成功提示“已删除 {{count}} 个文件，7 天内可在回收站恢复。” |
| **批量收藏** | 未收藏项加入个人素材根目录，已收藏项跳过；成功说明本次新增数及已收藏数，保留原历史记录<br>文案：<br>1. 全部新增：已收藏 {{新增数}} 个文件至素材。<br>2. 部分已收藏：已收藏 {{新增数}} 个文件，跳过 {{已收藏数}} 个已收藏文件。<br>3. 全部已收藏：所选文件均已收藏，无需重复收藏。 |
| **批量引用** | 直接跳转至店铺经营工作台，按上传文件附件的规则执行。 |

## 3 素材与文件夹管理

### 3.1 素材空间划分

- 为素材增加个人及企业的空间划分
  - 个人素材包含本人上传文件及已收藏历史文件；
  - 企业素材包含成员直接上传文件和个人发布形成的企业副本。所有企业成员可读
- 若用户身份为个人，则没有企业空间功能，仅企业成员有。

### 3.2 文件夹管理

个人空间文件夹由本人维护，企业文件夹由所有有效企业成员共同维护，企业成员与管理员权限一致。仅支持一级文件夹；每个个人空间及每个企业分别最多 20 个有效文件夹，根目录不计数。

| 功能 | 操作及结果 | 校验和提示 |
| --- | --- | --- |
| **新建** | 用户确定个人或当前企业范围后输入名称，保存成功创建空文件夹 | 名称必填，去首尾空格，最多 40 字；<br>1.为空提示“请输入文件夹名称”，<br>2.重名提示“已有同名文件夹，请更换名称。”；<br>3.达到上限提示“最多可创建 20 个文件夹。” |
| **重命名** | 带入原名称，用户修改并确认后仅更新名称，文件和目录标识保留 | 与新建使用同样命名校验；<br>名称未变化直接结束，不重复写入；<br>成功提示“文件夹已重命名。” |
| **删除** | 二次确认后删除目录，将全部所属文件移回同一空间根目录，释放目录额度 | 展示二次确认弹窗：标题“删除文件夹‘{{folderName}}’？”，<br>说明“文件夹内素材将移回根目录，不会删除素材。文件夹删除后不可恢复。” |

- 删除包含不同上传人文件的企业文件夹时，操作成员将全部所属文件移回企业根目录，文件责任人不变。
- 文件夹删除不进入回收站，。
- 原目录中的已删除文件保留在回收站，之后恢复到根目录。
- 新建与删除并发时仍需保证有效文件夹不超过 20 个；删除目录与解除文件归属必须一起完成，失败不返回成功状态。

### 3.3 素材分类与查询

| 项目 | 规则 |
| --- | --- |
| **分类** | 全部、图片、视频、文档、其他，沿用「创作历史」的识别规则 |
| **搜索字段** | 文件名称、说明、标签、关联商品名称，沿用「创作历史」的规则 |
| **搜索范围** | 当前个人／企业空间，可进一步限定具体文件夹 |
| **搜索方式** | 不区分大小写的包含匹配；范围、目录、类型、关键词共同约束查询 |
| **排序** | 默认更新时间倒序，允许更新时间正序；缺少更新时间时使用创建时间，同值时按文件名正序 |
| **时间更新** | 上传、重命名、移动、内容维护更新更新时间 |
| **分页** | 默认 20 项，沿用「创作历史」的规则 |

支持用户选择文件、多文件上传，上传位置取用户当前所在目录

上传文件的规则同“文件管理”的 文件类型限制

### 3.5 文件维护与批量处理

#### 3.5.1 重命名

- 点击重命名 - 打开修改弹窗- 支持修改文件名
- 文明名字段规则：去首尾空格，最多 200 字，不允许 \ / : * ? " < > 及竖线。允许不同文件使用同一名称，按文件标识区分。
- 名称为空提示“请输入文件名称。”；包含禁用字符时指出不可用字符。
- 确认成功更新文件名及更新时间，提示“文件已重命名。”；
- 文件内容、文件夹归属的关联不变。
- 取消或名称未修改时不写入。

#### 3.5.2 移动

用户选择同一空间内的根目录或有效文件夹并确认，将文件归属改为目标目录，更新文件更新时间。不可通过移动改变个人／企业归属。

目标为原位置时不重复写入。成功提示“素材已移动到目标位置。”；

目标失效提示“目标文件夹已不存在，请重新选择。”，

保留选择供修改。文件标识、内容和责任人保持不变。

#### 3.5.3 删除

- 点击删除弹出确认弹窗，提示：所选 {{count}} 项将在回收站保留 7天，到期自动销毁
- 确认后移入该空间回收站，取消未发送聊天框中的对应引用
- 企业副本删除不影响个人原件，个人原件删除不影响企业副本。保留期内保存责任人、目录、内容和名称供恢复使用。

#### 3.5.4 批量操作

| 批量操作 | 规则 |
| --- | --- |
| **批量下载** | 同“创作历史”的规则 |
| **批量删除** | ●个人空间及企业共享空间均支持批量删除操作，企业成员与管理员均可删除所选企业素材<br>●同“创作历史”的规则，批量删除说明为“删除所选 {{count}} 个文件？删除后在回收站保留 7 天，到期自动销毁。”。 |
| **批量移动至** | ●个人空间及企业共享空间均支持批量移动操作，企业成员与管理员均可移动所选企业素材<br>●逻辑同“3.5.2 移动” |
| **批量引用** | 同“创作历史”的规则 |
| **批量发布至** | 仅个人空间支持批量发布，逻辑同 “3.6 发布至企业空间” |

## 4 风格管理

### 4.1 用途说明

保存常用的视觉风格，延续内容创作的视觉基调。风格方案用于复用店铺、商品系列或活动的光线、色调、材质、背景与构图要求，减少每次商品图片、视频创作时重复描述。

风格方案由用户在“资产库-风格”中创建；发布至企业后形成独立共享副本，供当前企业成员使用。

### 4.2 创建／编辑风格方案

| 字段 | 必填规则 | 内容与校验 |
| --- | --- | --- |
| **方案名称** | 必填 | 去除首尾空格，字符唯一，最多 60 字；<br>placeholder：例如：商品图日常视觉/护肤系列·自然光； |
| **风格描述** | 必填 | 最多 2000 字，可描述光线、色调、材质、背景和构图；仅空格视为未填写 |
| **参考图** | 选填 | 最多 5 张，JPG／PNG／WebP，单张不超过 5MB；支持上传或从有访问权限的有效素材图片中选择；按引用地址去重并保留确认顺序 |

- 创建与编辑共用字段和校验规则。编辑带入已保存内容；
- 保存更新内容和更新时间，保留方案标识、归属及最初发布人；

取消不改变原方案。

从创作历史或素材图片发起创建时，带入该图片及可修改的初始名称，不改变原图片。

第一张参考图作为方案代表图；无参考图时采用系统默认标识。

保存前可确认名称、描述及全部参考图。

存在读取中或上传失败的图片时不能保存，需等待完成、重试或移除失败项。

| 情况 | 处理及提示文案 |
| --- | --- |
| **名称为空** | 不保存，提示“请输入方案名称。” |
| **描述与参考图均为空** | 不保存，提示“请填写风格描述或添加参考图。” |
| **参考图超限** | 拒绝超额图片，提示“参考图最多 5 张。”，保留已有内容 |
| **图片格式或大小不符合要求** | 拒绝该图片，提示“请上传 JPG、PNG 或 WebP 图片，单张不超过 5MB。” |
| **创建成功** | 提示“风格方案已保存。”，归入本人个人风格 |
| **编辑成功** | 提示“风格方案已更新。” |
| **保存失败** | 提示“保存失败，请重试。”，保留填写内容，不覆盖原方案 |

新用户首次初始化个人空间时，配置 1 个默认风格方案，包含名称及有效描述或参考图。默认方案为独立个人副本，支持普通个人方案的全部操作；平台模板更新不覆盖个人修改。每个个人空间仅初始化一次，编辑、删除后不自动补回；初始化失败可重试，但不重复创建已成功配置的方案。不自动创建企业副本或加入聊天框引用。

### 4.3 列表查看、排序与分页

| 功能 | 逻辑规则 |
| --- | --- |
| **查询范围** | 分别查询“我的”和“企业共享”，不合并全部资源；我的仅返回本人方案，企业共享仅返回当前企业有效方案，均排除已删除及已销毁资源 |
| **内容查看** | 支持确认方案名称、风格描述及参考图；无描述时不补充占位描述。本人方案及当前企业全部有效方案可进入编辑，企业成员与管理员权限一致 |
| **企业方案信息** | 查看或编辑时提供最初分享人及最新编辑时间；更新方案内容不改变最初分享人 |
| **搜索** | 按方案名称、风格描述进行不区分大小写的包含匹配，仅搜索当前范围 |
| **排序** | 固定按更新时间倒序；相同时间按方案标识升序，保证结果稳定 |
| **分页** | 默认每页 20 项，可选 10／20／50 项；总数仅统计当前范围及搜索条件下的有效方案 |
| **条件变化** | 切换范围、修改关键词或每页数量后回到第一页；删除导致当前页超出页数时返回最后一个有效页 |
| **无数据** | 我的允许创建方案；企业共享说明暂无共享方案，可将本人个人方案发布至企业；搜索无匹配时允许清空或修改关键词 |

创建入口仅在“我的”提供。创建、编辑、发布和删除成功后重新计算相应查询结果及总数；编辑方案按最新更新时间参与排序。

### 4.4 引用

1. 引用前检查方案未删除、未销毁且当前用户有访问权限。不可用时拒绝加入，提示“该风格方案已失效或无访问权限，请重新选择。”。
2. 从风格管理点击引用，跳转创作聊天框并带入方案；从聊天框资产库选择时直接加入当前聊天框，选择器保持打开。均不自动发送。
3. 一次创作最多引用 1 个风格方案。已有其他方案时直接替换，已有文字、普通附件和模特引用保留；重复引用同一方案不重复添加。
4. 方案名称、风格描述及全部参考图整体带入，无需逐项勾选。仅有描述或仅有参考图时，按实际保存内容引用。生成 Prompt 按 7.2 执行。
5. 移除聊天框中的风格仅取消本次使用，不删除原方案。发送前再次检查有效状态与权限，失效时保留创作内容并要求更换或移除引用。

### 4.5 删除

本人可删除自己的个人方案；企业方案删除权限按 4.7 校验。

| 步骤或结果 | 规则及提示 |
| --- | --- |
| **二次确认** | 标题“删除该风格方案？”，说明“删除后在回收站保留 7 天，到期自动销毁，不会删除方案引用的原素材。”；按钮“取消”“删除” |
| **确认成功** | 记录删除时间，方案进入对应空间回收站，从有效列表和新引用候选中移除；取消未发送聊天框中的该方案引用；提示“已移入回收站，7 天内可恢复。” |
| **取消** | 保持原方案及引用状态 |
| **删除失败** | 不改变原方案，提示“删除失败，请重试。” |
| **无维护权限** | 拒绝删除，提示“无权限删除该风格方案。” |

个人原件和企业副本独立删除，互不影响；删除方案不删除参考图对应的独立素材。回收站期限、恢复和到期销毁按第 8 章执行。

### 4.6 发布至企业

| 项目 | 规则及提示 |
| --- | --- |
| **发布条件** | 用户当前为有效企业身份，源方案属于本人个人空间且有效；个人身份不能发布，提示“请切换至企业身份后发布。” |
| **发布位置** | 直接加入当前企业风格库，无需选择素材文件夹；企业方案不提供再次发布 |
| **发布结果** | 创建独立企业方案，复制确认时的名称、描述和参考图，记录源方案标识、企业标识、发布人及发布时间，发布人用于追溯，当前企业全体有效成员均可维护企业副本；个人原件保留 |
| **发布成功** | 提示“已发布至企业空间。”；个人方案后续编辑不自动覆盖企业副本，企业副本编辑也不影响个人原件 |
| **已有有效副本** | 按源方案标识及企业标识判断；不重复创建、不覆盖，提示“该风格已发布至企业空间。”；同名但不同源方案允许发布 |
| **原企业副本已删除** | 允许再次发布创建新副本，旧回收站记录继续按原期限保留；恢复旧副本时若已有同源有效副本，拒绝恢复并提示“企业空间已有该风格，无需重复恢复。” |
| **发布失败** | 不创建不完整副本，保留个人原件，提示“发布失败，请重试。” |
| **身份或源方案失效** | 确认时再次校验；企业身份失效提示“当前企业身份已失效，请重新选择企业。”；源方案失效提示“该风格方案已失效，请刷新后重试。” |

同一次发布提交需保证幂等，避免重复点击产生多个企业副本。发布不开放源方案关联的其他个人资源或源对话。

## 5 模特管理

### 5.1 用途和场景说明

保存商品内容生产中需要反复使用的人物，使同一模特可在多次图片、视频创作中作为人物参考。

| 经营场景 | 使用方式 |
| --- | --- |
| **服装穿搭、上身及细节展示** | 复用人物主图及三视图，减少不同款式、不同视角创作时人物不一致的问题 |
| **美妆、个护等商品出镜** | 选择符合本次内容要求的模特，结合商品图和创作要求生成使用场景内容 |
| **玩具、宠物、母婴、家具、3C 等生活场景** | 按具体任务选择人物年龄、体型及补充特征，生成商品互动或生活场景内容 |
| **店铺系列内容及团队协作** | 将常用自建模特发布至企业，供成员复用人物参考 |

人物图用于约束人物外观，商品外观、动作、场景及风格由本次创作的其他输入确定。三视图为可选参考，不承诺仅凭引用即可保证所有生成结果完全一致。

模特分“我的”和“企业共享”查询，不合并全部资源。我的包含本人 AI 创建、上传和官方收藏；企业共享仅包含当前企业有效自建模特。列表及详情以名称和人物图供确认，存在三视图时可切换确认；不强制展示人物属性或描述。

查询支持名称不区分大小写的包含搜索，固定按更新时间倒序，同时间按模特标识升序。默认每页 20 项，可选 10／20／50 项，总数只统计当前条件下的有效记录。范围、关键词或每页数量变化后回第一页；删除导致页码超界时返回最后一个有效页。创建入口仅在我的提供。

### 5.2 创建模特

| 创建方式 | 输入 | 保存结果 |
| --- | --- | --- |
| **AI 创建** | 人物参数、补充特征及可选参考图 | 生成并确认后保存为本人自建模特，可包含主图和三视图 |
| **收藏平台模特** | 选择预置平台模特 | 建立本人收藏关系，保留官方来源，不转为自建模特 |
| **上传模特** | 上传人物照片并确认使用权限 | 保存为本人自建模特，上传图作为主图 |

#### 5.2.1 AI 创建

##### 5.2.1.1 AI 定制参数

| 字段 | 规则及预设 |
| --- | --- |
| **模特名称** | 必填，去首尾空格，最多 60 字，用于资源识别 |
| **性别** | 必填，女／男，支持自定义 |
| **人物背景** | 选填，中国／东亚／东南亚／南亚／中亚／中东／欧洲／拉丁美洲／非洲，支持自定义；默认不选，placeholder：请选择或自定义人物背景 |
| **年龄段** | 必填，青少年／青年／中年／老年，支持具体年龄等自定义值 |
| **体型** | 必填，纤细／标准／微胖／大码，支持自定义 |
| **补充特征** | 选填，最多 1000 字，可补充人设、肤色、发型、妆容、表情、服装、姿态等要求。placeholder：例如：上班族、运动达人等人设；也可补充肤色、发型、妆容、服装和姿态等要求。 |
| **参考图** | 选填，最多 1 张，JPG／PNG／WebP，不超过 3MB，可更换和移除 |

人物属性自定义值最多 60 字，保存去除首尾空格后的有效值。默认性别女、人物背景不选、年龄青年、体型标准。人设通过补充特征填写，随该字段原文传入生成提示词，不单独设置参数或默认人设。所有销售市场提供完整人物背景预设，不按市场绑定或限制，不为地域预设固定肤色、五官或发型。名称只作为资源元数据，不要求出现在生成图中。

人物属性支持选择预设或在该属性的自定义输入中填写，主字段仅显示当前值。选择预设替换已有自定义值；填写自定义内容后使用该内容作为有效值，按 Enter 完成输入。必填属性清空后不能生成，人物背景清空后按未指定处理。

##### 5.2.1.2 生成流程与状态规则

| 操作 | 输入依据 | 成功结果 |
| --- | --- | --- |
| **首次生成** | 当前有效人物参数、补充特征及可选参考图 | 一张人物主图，保存生成人物时使用的参数 |
| **重新生成** | 最新确认的人物参数、补充特征及参考图 | 新主图替换当前结果，重置上一版调整记录及三视图 |
| **调整人物** | 当前主图与用户本次补充提示词 | 原图作为图像输入、补充提示词原文作为文本输入，得到新主图，原三视图失效 |
| **生成三视图** | 当前成功主图与固定三视图 Prompt | 正面、侧面、背面组合图，与当前主图关联 |
| **再次生成三视图** | 同一当前主图与固定三视图 Prompt | 替换三视图，人物主图保持不变 |
| **保存** | 当前最新成功主图、生成人物时使用的参数、可选三视图及参考图 | 创建一份可复用模特资源 |

- 每次人物生成只产生一张结果；存在成功主图后即可保存，三视图为可选内容。
- 调整人物的补充提示词必填，最多 1000 字；取消调整不改变现有结果。调整仅提交本次用户提示词与当前主图，人物参数与用户补充描述保留在模特资源中，不拼入本次提示词。
- 生成中保留上一成功结果，禁止同一流程重复生成及保存；结果与其生成参数对应保存。
- 生成失败保留上一成功结果与本次输入，允许重试；不能以失败或未交付结果替换成功记录。
- 修改主图后必须使其旧三视图失效；三视图需保持同一人物、发型、体型、服装、比例和光照一致。
- 关闭未保存的创建流程不创建正式模特记录。

##### 5.2.1.3 模特生成 Prompt

###### 5.2.1.3.1 表单变量

| 表单内容 | 变量 | 用途 |
| --- | --- | --- |
| **模特名称** | {{name}} | 保存资源名称，不加入生成提示词 |
| **性别** | {{gender}} | 直接采用用户确认的预设或自定义值 |
| **人物背景** | {{appearance}} | 采用用户确认的预设或自定义值；为空时省略对应行 |
| **年龄段** | {{age}} | 直接采用用户确认的年龄段或自定义年龄 |
| **体型** | {{bodyType}} | 直接采用用户确认的体型 |
| **补充特征** | {{features}} | 采用用户填写的补充描述；为空时省略对应行 |
| **参考图** | {{referenceImage}} | 存在时作为独立图像输入，不将图片地址拼入文本 |

变量使用通过字段校验的原始值。自定义值与预设值采用相同传参规则。

###### 5.2.1.3.2 首次生成与重新生成

首次生成与按表单重新生成使用同一模板，输出数量固定为 1。

```text
生成一张可用于商品图片和视频创作的人物模特图。
性别：{{gender}}
人物背景：{{appearance}}
年龄段：{{age}}
体型：{{bodyType}}
补充特征：{{features}}

人物正面自然站立，全身完整入镜，人物特征清晰，背景简洁，光线均匀自然。
服装简洁；补充特征明确指定的人设、服装、发型、妆容、表情和姿态按用户要求执行。
只生成同一位人物，不添加文字、姓名、水印或额外人物。
```

参考图存在时，将该图作为图像输入，并追加固定指令：

```text
参考所提供图片中的人物形象，结合以上用户参数生成。
```

参考图为空时省略该指令；人物背景为空时省略“人物背景”行；补充特征为空时省略“补充特征”行。

###### 5.2.1.3.3 根据结果调整人物

| 输入 | 规则 |
| --- | --- |
| **图像** | 当前成功主图作为原图 |
| **文本** | 用户本次补充提示词原文 {{adjustment}} |
| **输出数量** | 1 |

```text
{{adjustment}}
```

该文本直接作为 AI 编辑指令，不拼接人物参数、模板前后缀或历史调整内容。成功后新图成为下一次调整的原图，模特保存时保留最终人物图、生成人物时的参数及用户补充描述。

###### 5.2.1.3.4 固定三视图 Prompt

输入仅使用当前成功主图、以下固定提示词及图像输出配置，生成一张三视图组合图：

```text
请基于提供的人物原图，生成同一人物的全身三视图组合图，包含正面、侧面和背面。
三个视图按正面、侧面、背面的顺序排列，人物等比例、等高度，完整展示头部至脚部。
严格保持原图人物的身份、面部特征、发型、体型、肤色、服装及配饰一致。
人物自然站立，背景统一简洁，光线和色调保持一致；侧面为标准侧身视角，背面为标准背身视角。
仅输出一张三视图组合图，不添加文字、标签、水印或其他人物。
```

首次及再次生成三视图使用同一固定 Prompt，不拼接用户表单值和历史调整提示词。

#### 5.2.2 收藏平台模特

1. 用户查询平台预置模特并选择收藏，成功后加入我的模特，提示“已收藏至我的模特。”。
2. 同一用户对同一平台模特最多一份有效收藏；重复收藏不新增，提示“已收藏。”。
3. 官方收藏保留平台名称、主图及可选三视图，并标注官方来源；不支持修改名称、图片和人物属性，不支持发布至企业。
4. 引用未收藏的平台模特时，先建立收藏关系，再加入当前创作引用；已经收藏时复用原关系。收藏失败不加入引用，提示“收藏失败，请重试。”。
5. 新用户首次初始化个人空间时自动收藏 1 个预置官方模特，不自动加入聊天框。初始化仅执行一次，移除后不补回；失败允许重试，成功项不重复执行。风格和模特分别记录初始化结果。

#### 5.2.3 上传模特

| 字段 | 规则 |
| --- | --- |
| **模特名称** | 选填，去首尾空格，最多 60 字；未填写时使用“上传模特” |
| **人物照片** | 必填，单张 JPG／PNG／WebP，最多 3MB；支持更换，保存时采用最后确认的有效图片 |
| **使用权限确认** | 必须确认已获得照片及人物形象的使用权限 |

上传成功后可确认主图再保存。缺少照片时提示“请上传人物照片。”；格式或大小不符时提示“请上传 JPG、PNG 或 WebP 图片，大小不超过 3MB。”；未确认使用权限时提示“请确认已获得照片与人物形象的使用权限。”。

上传照片不自动推断或补齐性别、人物背景、年龄及体型，不将未知属性写成默认值。上传方式不包含 AI 创建流程中的三视图生成。

AI 创建和上传保存成功提示“模特已保存。”，创建个人模特资源；保存失败提示“保存失败，请重试。”并保留填写内容与有效图像。未保存退出不创建模特记录。

### 5.3 平台模特预置

平台模特通过预置配置提供，本期不提供后台新增、编辑或上下架功能。

| 配置项 | 规则 |
| --- | --- |
| **模特标识** | 稳定且唯一，用于收藏去重及引用关联；名称变化不改变标识 |
| **模特名称** | 必填，用于用户识别和搜索 |
| **主图** | 必填，提供可用且具有使用授权的人物图像 |
| **三视图** | 选填，与主图保持同一人物 |
| **来源** | 固定为官方，用户收藏后保持该来源 |
| **默认对象** | 指定 1 个有效模特，用于新用户个人空间初始化 |
| **更新时间及有效状态** | 通过预置配置管理，供排序及资源有效性校验；无效对象不允许新收藏或新引用 |

平台目录支持名称搜索、更新时间倒序及与个人模特相同的分页规则。用户收藏、移除和引用不修改平台源数据。更新预置内容时保留稳定标识；官方收藏始终关联平台对象，不生成可编辑的个人副本。已收藏对象不可用时保留来源记录，阻止新引用并提示“该官方模特已不可用，请选择其他模特。”。

### 5.4 编辑

仅支持修改 AI 创建或上传模特的名称，不支持修改已保存模特的主图、三视图或人物参数。需要重新生成人物时，通过创建流程保存为新的模特资源。

| 情况 | 处理规则及提示 |
| --- | --- |
| **名称校验** | 必填，去首尾空格，最多 60 字；允许同名，以模特标识区分 |
| **提交与取消** | Enter 或失焦提交，Esc 取消；名称未变化不写入；Enter 提交空值提示“请输入模特名称。”，空值失焦恢复原名称 |
| **修改成功** | 仅更新名称及更新时间，保留人物图像、来源和其他记录，提示“模特名称已更新。” |
| **修改失败** | 保留原记录及待修改内容，提示“修改失败，请重试。” |
| **官方收藏** | 禁止修改，提示“官方模特不支持编辑。” |
| **无维护权限** | 拒绝修改，提示“无权限编辑该模特。” |

本人可编辑个人自建模特；企业自建模特按 5.8 的权限执行。个人原件与企业副本独立修改。

### 5.5 引用

1. 引用前检查模特及图像有效性和访问权限，不可用时提示“该模特已失效或无访问权限，请重新选择。”。
2. 从模特管理点击引用，跳转创作聊天框并加入模特引用；从聊天框资产库选择时，直接加入当前聊天框并保持选择器打开。均不自动发送。
3. 一次创作支持引用多个模特，新选择加入现有模特集合；已有文字、普通附件、风格和其他模特保留，重复选择同一模特不重复加入。发送时按当前生成模型能力校验图像输入数量。
4. 常规模特引用包含名称、主图及已有三视图；在详情中明确引用某张图时，仅带入所选图。下载也以当前确认的图像为对象。
5. 模特生成指令按 7.3 执行，表达本次创作中的人物采用所引用模特；不将保存名称、人物描述或背景参数作为额外外观要求重复拼入。
6. 移除聊天框引用仅取消本次使用，不删除模特或解除官方收藏。发送前再次检查有效性和权限，失效时保留创作内容并要求移除或更换。

### 5.6 删除

| 对象 | 二次确认 | 确认后的结果 |
| --- | --- | --- |
| **AI 创建、上传模特** | 标题“删除该模特？”，说明“删除后在回收站保留 7 天，到期自动销毁。”；按钮“取消”“删除” | 进入对应空间回收站，记录删除时间，移出有效列表与新引用候选，并取消未发送聊天框中的该引用；提示“已移入回收站，7 天内可恢复。” |
| **官方收藏** | 标题“移除该官方模特？”，说明“仅从我的模特中移除，之后可重新收藏。”；按钮“取消”“移除” | 解除本人收藏并取消未发送引用，不进回收站、不删除平台数据；提示“已移除收藏。” |

个人原件与企业副本独立删除，互不影响；删除模特不删除独立保存的参考原图。自建模特的恢复、计时和到期销毁按第 8 章执行，官方收藏移除后可通过再次收藏找回。

取消不改变数据；删除失败提示“删除失败，请重试。”，移除收藏失败提示“移除失败，请重试。”，保留原记录。不属于当前企业或企业成员身份失效时拒绝删除，提示“无权限删除该模特。”。

### 5.7 发布至企业

| 项目 | 规则及提示 |
| --- | --- |
| **发布条件** | 当前为有效企业身份，源资源是本人有效的 AI 创建或上传模特；个人身份提示“请切换至企业身份后发布。” |
| **官方限制** | 官方收藏不提供发布功能；执行请求时拒绝，提示“官方模特不支持发布至企业空间。”；企业模特不提供再次发布 |
| **发布结果** | 直接创建当前企业的独立自建模特副本，复制名称、主图、已有三视图及人物记录；保留个人原件，记录源模特标识、企业标识、发布人及发布时间 |
| **发布成功** | 提示“已发布至企业空间。”；个人原件与企业副本后续独立维护，不自动相互覆盖 |
| **已有有效副本** | 按源模特标识和企业标识判断；不重复创建、不覆盖，提示“该模特已发布至企业空间。”；同名但不同源对象可发布 |
| **原副本已删除** | 可重新发布创建新副本，旧回收站记录按原期限保留；恢复旧副本时存在同源有效副本则拒绝恢复，提示“企业空间已有该模特，无需重复恢复。” |
| **身份或源资源失效** | 拒绝发布，分别提示“当前企业身份已失效，请重新选择企业。”或“该模特已失效，请刷新后重试。” |
| **发布失败** | 不创建不完整副本，不改变个人原件，提示“发布失败，请重试。” |

同一次确认保证幂等，避免重复点击创建多个副本。发布仅开放该模特所包含的人物内容，不开放源对话或其他个人素材。

### 5.8 企业模特查看、引用、删除及权限

企业共享只返回当前企业有效自建模特，排除官方来源；查询和展示规则按 5.1 执行。发布人用于追溯，不限制维护权限；当前企业全体有效成员均可维护企业副本。

| 功能 | 企业普通成员 | 企业管理员 |

| **下载、引用** | ✓ 全部有效企业自建模特 | ✓ 全部有效企业自建模特 |
| **修改名称** | ✓ 全部企业自建模特 | ✓ 全部企业自建模特 |
| **删除、回收站恢复** | ✓ 全部企业自建模特 | ✓ 全部企业自建模特 |
| **批量删除** | ✓ 全部企业自建模特 | ✓ 全部企业自建模特 |

| **将官方收藏发布至企业** | ✕ | ✕ |

每次读取、引用、改名、删除、恢复和发布都校验有效企业成员状态及资源归属，不按成员角色或发布人限制企业自建模特维护。成员退出企业或权限变化后停止相应操作，并复核未发送的企业模特引用。企业成员维护企业副本不获得个人原件的访问或修改权限。

## 6 创作资产引用

### 6.1 列表查看与查询

聊天框通过资源库或 `@` 查找并引用**创作历史、素材、风格、模特**。仅返回本人或当前企业有访问权限的有效资源，排除已删除、已销毁及到期不可用资源。

| 资源 | 列表内容与范围 | 筛选与搜索 | 排序 |
| --- | --- | --- | --- |
| **创作历史** | 本人有效历史文件，展示文件名称及图片／视频缩略图，文档和其他文件展示对应文件图标 | 全部／图片／视频／文档／其他；按文件名称、标签搜索 | 创建时间倒序，不提供排序切换 |
| **素材** | 我的或当前企业共享文件，文件展示规则与创作历史一致 | 个人／企业范围、全部文件夹／未分组／具体文件夹、文件类型；按文件名称、标签搜索 | 默认更新时间倒序，可切换正序 |
| **风格** | 我的或当前企业共享方案，展示名称及第一张参考图；无参考图时使用默认标识 | 我的／企业共享；按方案名称、风格描述搜索 | 更新时间倒序 |
| **模特** | 我的自建及官方收藏、当前企业共享自建模特；以人物缩略图和名称确认对象，不展示人物描述；企业范围排除官方来源 | 我的／企业共享；按模特名称搜索 | 更新时间倒序 |

搜索不区分大小写，采用包含匹配；筛选与关键词共同生效。切换资源类型重置搜索与该类型筛选；切换个人／企业范围后重置文件夹为全部。查询条件变化不清除已引用内容。

### 6.2 分页

四类资源分别分页，默认每页 20 项，可选 10／20／50 项；总数按当前范围、筛选及关键词统计。条件或每页数量变化后回第一页，页码超出范围时返回最后一个有效页。相同排序时间按资源标识升序，保证翻页稳定。

### 6.3 引用规则

| 资源 | 选择与引用规则 |
| --- | --- |
| **创作历史、素材** | 支持多选，按聊天框上传附件的格式、大小、数量及校验规则执行；与已上传附件合并去重，普通文件合计最多 20 个，不单独增加资源库额度 |
| **风格** | 最多选择 1 个；新选择替换原方案，名称、描述和全部参考图整体引用 |
| **模特** | 支持多选，不替换其他已选模特；同一模特按标识去重。常规引用带入主图及已有三视图，明确引用某张图时仅带入所选图 |

点击资源后立即加入聊天框，不需要确认，不自动发送；重复选择不重复添加。选择器保持打开，便于连续引用；内部切换范围、筛选、搜索或翻页不关闭，点击外部或按 Esc 关闭。

从资源管理发起引用时，跳转创作聊天框并带入选择；从聊天框资源库选择时留在当前创作。已有文字及其他引用保留。移除只取消本次引用，不删除资源或解除官方收藏。

### 6.4 发送与有效性校验

普通附件沿用上传规则：支持图片、视频及 PDF／TXT／DOCX／XLSX／CSV，单文件不超过 20MB。读取失败的文件不加入有效引用；普通附件超限提示“最多引用 20 个文件，请减少附件。”。

风格参考图及各模特图像随资源一并传入，发送时合并校验当前生成模型实际支持的格式及图像数量。超限提示“当前模型最多支持 {{limit}} 个输入文件，请减少附件。”，保留文字与引用，不自动删减已选模特或图片。

发送前检查创作文字、附件读取状态、资源有效性及当前企业成员状态；校验不通过时说明原因并保留输入。已删除、已到期或无访问权限的资源提示“素材已失效或无访问权限，请移除后重试。”。

发送成功清空本次文字和引用，失败保留并提示“发送失败，请重试。”。企业有效成员均可引用全部有效企业共享资源，不限制上传人或发布人。

商品／SKU 引用使用独立能力，知识来源按独立接入规则处理；本资源库选择范围为上述四类资源。


## 7 创作生成 Prompt

用户发送创作要求时，将聊天框中的文字、附件、风格及模特传入生成服务。发送前按 6.4 检查具体附件和输入限制。

### 7.1 通用结构

```text
{{userPrompt}}
{{taskParameterPrompt}}
{{stylePrompt}}
{{modelPrompt}}
```

用户任务、任务参数、风格指令、模特指令按顺序组合；不存在的部分省略。任务参数按“参数名称：用户确认值”逐行生成，不重复写入同一要求。

商品／SKU 资料作为商品事实输入，图片、视频及文档按目标工具的输入能力解析。文档内容作为参考资料处理；视觉风格不改写商品外观、规格等事实。

### 7.2 引用风格 Prompt

| 变量 | 来源 |
| --- | --- |
| **{{styleName}}** | 风格方案名称 |
| **{{styleDescription}}** | 已保存的风格描述 |
| **风格图像输入** | 方案全部参考图，标记用途为视觉风格参考 |

{{stylePrompt}} 使用以下模板：

```text
本次创作采用风格方案“{{styleName}}”。
风格要求：{{styleDescription}}
参考随附风格图片中的色调、光线、材质与构图，不将其中的其他商品或人物直接作为本次创作主体。
保持本次创作商品的真实外观、规格及该方案的视觉基调。
```

描述为空时省略“风格要求”行；参考图为空时省略参考图片指令。方案名称用于识别，不作为画面文字生成。

### 7.3 引用模特 Prompt

对每个引用模特分别使用以下模板，按引用顺序组合为 {{modelPrompt}}：

```text
本次创作人物采用所引用的模特“{{modelName}}”，以随附模特图片为人物参考，保持人物形象一致。
```

{{modelName}} 来自对应模特名称；图像输入使用该模特选定的主图、三视图或二者集合。多个模特的标识、名称与图像分组对应，保持人物参考独立。模特名称仅用于识别，不要求写入画面；本段不重复拼接原人物生成参数或调整历史。

## 8 回收站与异常处理

### 8.1 状态变更

| 动作 | 数据结果 | 后续规则 |
| --- | --- | --- |
| **删除文件、风格、自建模特** | 标记删除并记录时间 | 资源不再参与正常查询和新任务引用，按权限可恢复 |
| **删除文件夹** | 删除目录并解除文件归属 | 文件保留在同空间根目录，目录不进入回收站 |
| **移除官方收藏** | 解除本人收藏关系 | 平台源不变，可再次收藏 |
| **恢复文件** | 清除删除状态，恢复原空间及有效目录关系 | 原目录失效时恢复至根目录，历史文件继续按原有效期判断 |
| **恢复风格或自建模特** | 清除删除状态，恢复原归属 | 后续维护及引用重新按当前权限校验 |

个人资源仅本人可恢复；当前企业全体有效成员均可恢复企业回收站中的素材、风格及自建模特，不限制上传人、发布人或成员角色。恢复时复核成员状态和资源归属。

点击恢复后清除删除状态，返回原空间；原文件夹不存在则回根目录。成功提示“已恢复”；失败提示“恢复失败，请重试。”。恢复历史文件不重置创建时间，已超过 365 天且未收藏时提示“文件已超过创作历史保留期限，无法恢复。”；已收藏文件仍可恢复到个人素材。

恢复已发布企业副本前，按源资源和企业标识检查同源有效副本；已存在时不重复恢复，提示“企业空间已有该资源，无需重复恢复。”。恢复前同时执行 8.2 的期限校验。

### 8.2 保留期限与到期销毁

| 项目 | 规则 |
| --- | --- |
| **适用对象** | 个人及企业回收站中的文件、风格方案、自建模特；文件夹和官方收藏移除不进入回收站 |
| **保留期限** | 从成功删除时间起连续保留 7 × 24 小时，精确到时间点；不按自然日或零点计算 |
| **有效期判断** | 当前时间早于删除时间加 7 天时可恢复；等于或超过到期时间立即失效，不返回回收站列表和可恢复数量 |
| **剩余天数** | 剩余时间不少于 24 小时，向上取整为整数天，展示“7天”“2天”“1天”等；大于 0 且不足 24 小时展示“<1天”，文字标红；不展示小时和分钟 |
| **时间更新** | 剩余时间随实际时间更新；再次访问、恢复页面及执行恢复时重新校验，不延长保留期限 |
| **到期销毁** | 自动销毁该回收站资源记录及其独立持有的文件内容，移除失效引用与关联；不要求用户确认，无法恢复；共享底层文件仍被其他有效资源使用时不得一并删除 |
| **恢复后的计时** | 成功恢复后取消本次回收站计时；以后再次删除，从新的删除成功时间重新计算 7 天；恢复不延长创作历史本身的保留期限 |
| **重复删除** | 已在回收站的资源不重复创建记录、不重置删除时间 |
| **销毁边界** | 企业副本与个人原件独立计算；销毁一个不影响另一个。风格销毁不删除其引用的原素材，模特销毁不删除独立保存的参考原图 |
| **手动销毁** | 不提供永久删除或清空回收站功能 |

用户发起删除时，二次确认需明确“将在回收站保留 7 天，到期自动销毁”。删除成功提示“已移入回收站，7 天内可恢复。”。

恢复请求在资源已到期或已销毁时拒绝执行，提示“资源已到期销毁，无法恢复。”，同步移除失效记录并更新数量。到期销毁与恢复同时发生时只允许一个结果成功，不得恢复已销毁资源。清理重复执行不重复扣减或影响有效资源。

### 8.3 异常处理

| 异常 | 处理规则 |
| --- | --- |
| **查询无结果** | 区分尚无资源与查询不匹配；允许新建、上传或重新查询 |
| **文件夹额度不足** | 拒绝新建并说明上限，已有目录不受影响 |
| **格式、大小或文件读取失败** | 该文件不入库或不引用，返回原因，其余成功项保留 |
| **文件不做内置预览** | 按格式定位本机文件目录；无目录定位能力时完成原件下载并提供浏览器下载记录操作说明 |
| **解析／转换失败** | SVG 转换失败退回源码；其他失败保留有效原件下载，提示具体原因 |
| **发布或移动目标失效** | 不写入无效归属，允许改用有效目录或根目录 |
| **权限不足或成员身份变化** | 拒绝对应动作，重新校验可用资源与待提交引用 |
| **保存失败** | 提示“保存失败，请重试。”，保留填写内容及已上传成功的文件，原资源不被未成功保存的数据覆盖 |
| **重复提交** | 使用请求标识保证同一操作幂等，避免重复资源 |
| **并发修改或删除** | 检查资源版本及有效状态，冲突时返回原因，避免覆盖未确认内容 |

| **M00** | 默认模特初始化 | 首次个人空间初始化仅建立 1 个官方收藏，保持官方限制；不进入企业，移除后不自动补回 |

| **M04** | 企业模特 | 只返回自建来源，全部有效企业成员均可使用、改名、单个／批量删除及恢复，不限制发布人或成员角色 |
