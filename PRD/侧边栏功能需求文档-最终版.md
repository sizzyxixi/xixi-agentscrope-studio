# 侧边栏功能需求文档

| 文档属性 | 内容 |
|---|---|
| 文档状态 | 最终版 |
| 适用范围 | Agent 会话页右侧边栏 |
| 功能范围 | 文件列表、任务列表、文件预览、浏览器 |

## 1. 产品目标

侧边栏用于集中查看会话相关文件、跟踪任务进度，以及在不离开会话的情况下预览文件和访问网页。

用户在侧边栏中的操作不得中断当前会话，也不得覆盖 Chatbox 中尚未发送的内容。

## 2. 整体结构

侧边栏包含以下功能类型：

| 类型 | 说明 | 是否可关闭 |
|---|---|---|
| 文件列表 | 查看当前展示范围内的文件 | 否 |
| 任务列表 | 查看当前会话中的任务 | 否 |
| 文件预览 | 预览用户打开的文件 | 是 |
| 浏览器 | 访问会话链接或用户输入的网址 | 是 |

### 2.1 初始页签

1. 文件列表和任务列表为固定页签，始终存在。
2. 文件列表默认排在第一位，任务列表默认排在第二位。
3. 首次进入会话时，默认打开文件列表。
4. 文件预览页签和浏览器页签按用户操作动态创建。
5. `+` 按钮固定显示在页签栏末尾，用于新建浏览器页签。

### 2.2 页签通用规则

1. 当前页签使用选中状态展示。
2. 点击页签后切换内容，不刷新其他已打开页签。
3. 新建文件预览或浏览器页签后，立即切换到新页签。
4. 动态页签统一添加在现有页签末尾、`+` 按钮之前。
5. 页签标题空间不足时从中间省略；悬停后展示完整标题。
6. 页签超出可视宽度时，页签栏支持横向滚动，并保证当前页签始终可见。
7. 切换文件列表、任务列表、预览页签和浏览器页签时，分别保留各自的滚动位置和页面状态。

## 3. 文件列表

### 3.1 展示范围

文件展示范围按会话是否属于分组确定：

| 会话情况 | 文件展示范围 |
|---|---|
| 会话不属于任何分组 | 仅展示当前轮对话产生的文件产物 |
| 会话属于某个分组 | 展示该分组默认文件路径下的文件和文件夹 |

规则说明：

1. “当前轮对话”从用户最近一次发送消息开始，到用户发送下一条消息前结束。
2. 当前轮对话产生新文件后，文件列表自动更新。
3. 新一轮对话开始后，未分组会话的文件列表切换为新一轮范围，不继续展示上一轮文件。
4. 历史轮次文件仍保留在原消息中，可从历史消息重新打开。
5. 分组会话始终以分组默认文件路径为展示范围，不受对话轮次变化影响。
6. 会话切换分组后，文件列表立即切换到新分组的默认文件路径。
7. 分组没有默认文件路径时展示空状态，不回退到当前轮文件。
8. 默认文件路径无权访问或已失效时展示错误状态，不展示其他路径文件。

### 3.2 列表结构

未分组会话使用文件列表展示；分组会话按照默认路径中的目录结构展示。

每个文件项展示：

- 文件类型图标或图片缩略图。
- 完整文件名；空间不足时从中间省略。
- 文件大小。
- 最近更新时间。
- 文件当前状态。

每个文件夹项展示：

- 文件夹图标。
- 文件夹名称。
- 展开或收起状态。
- 文件夹内文件数量。

### 3.3 排序规则

| 展示模式 | 排序规则 |
|---|---|
| 当前轮文件 | 按文件生成完成时间倒序排列，最新文件在最前面 |
| 分组默认路径 | 文件夹排在文件前；文件夹和文件分别按最近更新时间倒序排列 |

文件仍在生成时展示在列表顶部；生成完成后按照完成时间重新排序。

### 3.4 空状态和错误状态

| 场景 | 展示内容 |
|---|---|
| 当前轮没有文件产物 | 当前对话还没有生成文件 |
| 分组默认路径为空 | 该文件夹中暂无文件 |
| 分组未设置默认路径 | 当前分组未设置默认文件路径 |
| 路径无权访问 | 无权访问当前文件路径 |
| 文件列表加载失败 | 文件列表加载失败，提供“重试”操作 |

## 4. 文件操作

文件项支持以下操作：

| 操作 | 触发方式 | 结果 |
|---|---|---|
| 打开 | 点击文件名、缩略图或“打开”操作 | 根据文件类型打开预览页签或浏览器页签 |
| 引用 | 点击“引用” | 将文件添加到 Chatbox 当前草稿 |
| 删除 | 点击“删除” | 确认后删除文件 |

桌面端在文件项 Hover 或键盘聚焦时展示操作；移动端通过更多菜单展示。

### 4.1 打开文件

1. 普通文件打开新的文件预览页签。
2. HTML 文件打开新的浏览器页签，不创建文件预览页签。
3. 同一文件已经存在预览页签时，切换到已有页签，不重复打开。
4. 文件被更新后，再次打开时刷新已有预览页签内容。
5. 文件不支持预览时，页签展示文件信息和下载操作。

### 4.2 引用文件

1. 点击“引用”后，将文件添加到 Chatbox 的附件区。
2. 引用文件不需要重新上传。
3. 引用文件计入 Chatbox 单条消息 20 个附件的数量上限。
4. Chatbox 已达到附件上限时，引用失败并展示数量上限提示。
5. 文件已删除、无权访问或正在生成时不能引用。
6. 用户可以在 Chatbox 中移除已经引用的文件。

### 4.3 删除文件

1. 删除前展示二次确认，说明删除后无法恢复。
2. 用户确认后执行删除；用户取消后不做任何修改。
3. 删除成功后，文件立即从文件列表移除。
4. 该文件已打开的预览页签同步关闭。
5. 该文件已添加到当前 Chatbox 草稿时，同步从附件区移除并提示用户。
6. 历史消息中的文件记录继续展示，但打开时提示文件已删除。
7. 无删除权限时不展示“删除”操作。
8. 文件删除失败时保留文件项，并提供“重试”操作。
9. 本需求只支持删除文件，不支持在侧边栏中删除文件夹。

## 5. 文件预览页签

### 5.1 页签展示

1. 页签标题使用文件名。
2. 页签图标使用文件类型图标。
3. 页签提供关闭按钮。
4. 预览区域顶部展示文件名、文件大小、更新时间、下载和引用操作。

### 5.2 预览类型

| 文件类型 | 预览方式 |
|---|---|
| 图片 | 图片预览，支持缩放和旋转 |
| PDF | 分页预览，支持缩放和页码跳转 |
| 文本、Markdown、日志和代码 | 文本预览，代码文件支持语法高亮 |
| 表格 | 表格预览，支持横向和纵向滚动 |
| 音频 | 音频播放器 |
| 视频 | 视频播放器 |
| Office 文档 | 转换后预览；转换失败时展示文件信息和下载操作 |
| 压缩包、安装包及其他不可预览文件 | 展示文件信息和下载操作 |
| HTML | 不进入文件预览，直接使用浏览器页签打开 |

### 5.3 预览异常

1. 文件加载中时展示加载状态。
2. 文件预览失败时展示失败原因，并提供“重新加载”和“下载原文件”。
3. 文件已删除时展示“文件已删除”，只保留关闭页签操作。
4. 文件失去访问权限时停止展示内容，并提示无权访问。

## 6. 任务列表

### 6.1 展示范围

1. 任务列表展示当前会话中已经创建的任务和子任务。
2. 分组不会改变任务列表范围。
3. 切换会话后，任务列表切换为目标会话的任务。
4. 任务状态变化时列表自动更新。

### 6.2 任务信息

每个任务项展示：

- 任务名称。
- 当前状态。
- 已完成步骤数和总步骤数。
- 最近更新时间。
- 子任务展开或收起入口。

任务状态包括：等待执行、执行中、等待用户操作、已完成、执行失败、已取消。

### 6.3 排序和定位

1. 执行中和等待用户操作的任务排在最前面。
2. 其他任务按最近更新时间倒序排列。
3. 子任务展示在所属任务下方，不参与一级任务排序。
4. 点击任务后，主会话定位到对应的任务过程或结果消息。
5. 对应消息已不存在时，保留任务信息并提示无法定位。
6. 任务列表只提供查看和定位，不在侧边栏中修改任务内容或执行状态。

### 6.4 空状态和错误状态

| 场景 | 展示内容 |
|---|---|
| 当前会话没有任务 | 当前会话暂无任务 |
| 任务列表加载失败 | 任务列表加载失败，提供“重试”操作 |

## 7. 浏览器

### 7.1 打开浏览器页签

以下操作新建浏览器页签并立即打开：

1. 点击会话消息中的网页链接。
2. 点击文件列表或会话消息中的 HTML 文件。
3. 点击侧边栏页签栏中的 `+` 按钮。
4. 在浏览器页签中打开新窗口或新页签链接。

点击 `+` 后打开空白浏览器页签，并自动聚焦地址栏。

### 7.2 多页签规则

1. 支持同时打开多个浏览器页签。
2. 每次点击链接均新建浏览器页签，不复用相同地址的已有页签。
3. 不限制用户打开的浏览器页签数量；超出可视宽度后通过页签栏横向滚动查看。
4. 每个浏览器页签独立保存访问地址、前进后退记录和页面滚动位置。
5. 浏览器页签标题优先使用网页标题；网页标题不可用时展示访问地址。
6. 页面加载中时，在页签中展示加载状态。

### 7.3 HTML 文件

1. HTML 文件使用浏览器页签打开并渲染页面内容。
2. HTML 中引用同目录下的图片、样式和脚本时，按文件原有相对路径加载。
3. HTML 文件标题优先使用页面标题；没有页面标题时使用文件名。
4. HTML 文件已删除或失效时，浏览器页签展示文件不可用提示。
5. HTML 页面中的链接继续在新的浏览器页签中打开。

### 7.4 浏览器操作

每个浏览器页签提供：

- 后退。
- 前进。
- 刷新或停止加载。
- 地址栏。
- 在系统浏览器中打开。
- 关闭页签。

地址栏规则：

1. 输入完整网页地址后按 `Enter` 访问。
2. 未输入协议时，自动按 HTTPS 地址访问。
3. 地址无效时不发起访问，并展示地址错误提示。
4. 页面无法访问时保留当前地址，并提供“重新加载”和“在系统浏览器中打开”。

### 7.5 Agent 浏览器操作

1. 浏览器支持 Agent 使用 Browser Use 访问网页、读取页面、点击、输入、滚动及切换页签。
2. Agent 操作与用户看到的浏览器页签保持一致，并实时展示“正在浏览”“正在点击”“正在输入”等状态。
3. 用户开始手动操作页面时，暂停 Agent 操作并切换为用户接管；用户可继续授权 Agent 执行。
4. 遇到登录、验证码、授权及提交、发布、付款、删除等敏感操作时，暂停执行并等待用户处理或确认。
5. Agent 仅可操作当前会话中的浏览器页签，不可操作文件预览页签。

## 8. 页签关闭规则

### 8.1 不可关闭页签

1. 文件列表和任务列表不展示关闭按钮。
2. 文件列表或任务列表处于当前页签时，关闭快捷键不生效。

### 8.2 可关闭页签

1. 文件预览页签和浏览器页签展示关闭按钮。
2. 点击关闭按钮后立即关闭对应页签。
3. 聚焦动态页签时，支持 `Ctrl/Cmd + W` 关闭当前页签。
4. 关闭浏览器页签时，同时清除该页签的访问记录。
5. 关闭文件预览页签不删除原文件。

### 8.3 关闭后的页签选择

1. 关闭当前页签后，优先切换到右侧相邻页签。
2. 右侧没有页签时，切换到左侧相邻页签。
3. 所有动态页签均被关闭后，切换到文件列表。
4. 关闭非当前页签时，当前页签保持不变。

## 9. 会话切换与状态保留

1. 每个会话独立保存侧边栏状态。
2. 切换会话后，展示目标会话上次打开的页签和当前选中页签。
3. 返回原会话时，恢复该会话的文件预览页签、浏览器页签和滚动位置。
4. 页面刷新后，恢复固定页签和当前选中页签；不自动恢复尚未完成加载的网页。
5. 会话被删除后，清除该会话保存的侧边栏状态，不删除分组默认路径中的文件。

## 11. 验收标准

### 11.1 页签

1. 文件列表和任务列表始终存在且无法关闭。
2. 文件预览和浏览器页签可以分别关闭。
3. 点击 `+` 可以连续创建多个浏览器页签。
4. 页签超出宽度后可以横向滚动，当前页签始终可见。
5. 关闭当前动态页签后，按照右侧优先、左侧次之的规则切换页签。

### 11.2 文件列表

1. 未分组会话只展示当前轮对话文件产物。
2. 分组会话只展示分组默认文件路径中的文件。
3. 当前轮或默认路径中的文件变化后，列表自动更新。
4. 文件可以打开、引用和删除。
5. HTML 文件打开浏览器页签，其他可预览文件打开文件预览页签。
6. 删除文件后关闭对应预览页签，并移除当前草稿中的文件引用。

### 11.3 任务列表

1. 任务列表只展示当前会话中的任务和子任务。
2. 任务状态变化后列表自动更新。
3. 点击任务可以定位到对应会话内容。
4. 任务列表不提供任务编辑和状态修改操作。

### 11.4 浏览器

1. 点击会话链接会新建浏览器页签并访问对应地址。
2. HTML 文件会在浏览器页签中正常渲染。
3. 浏览器支持多页签、地址输入、后退、前进和刷新。
4. 相同地址可以同时打开在不同浏览器页签中。
5. 每个浏览器页签独立保留访问记录和滚动位置。
6. Agent 可在用户可见的浏览器页签中完成网页浏览和交互操作，并展示当前操作状态。
7. 用户接管页面或遇到敏感操作时，Agent 会暂停执行并等待用户操作或确认。
